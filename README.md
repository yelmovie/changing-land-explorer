# 움직이는 지오밸리

현재 단계: **Phaser 기반 탐험 프로토타입 구현 및 검증**. 지도 이동, 5개 장소 × 활동 2장 × 3단계(총 30개 발견), 관찰 수첩, 도구 보상, 마지막 응용 도전과 인증서를 구현했다. 최신 구현 기준은 [탐험 고도화 기록](docs/ADVENTURE_UPGRADE.md)이다.

## 실행과 검증

Node.js 20 이상에서 별도 패키지 설치 없이 실행한다.

```sh
npm run dev      # http://localhost:5177
npm run check    # JavaScript 문법 검사
npm test         # 학습·저장·진행 규칙 회귀 검사
npm run build    # dist/ 정적 빌드
npm run preview  # 빌드 결과를 같은 주소에서 확인
```

실행 에셋과 Phaser 3.90.0은 `public/assets/`에 포함한다. 이미지 재가공 스크립트는 제작 당시의 로컬 원본·Sharp 경로를 사용하며 앱 실행과 빌드에는 필요하지 않다. 원본 이미지·ZIP·중간 백업과 `dist/`는 Git에 넣지 않고 기존 로컬 폴더에 보존한다.

저장소: https://github.com/yelmovie/changing-land-explorer

탐구 설계 배경: [태블릿 탐구 경험 설계](docs/TABLET_EXPLORATION_DESIGN.md). 10개 활동의 조작·피드백·개인 증거·완료 조건·화면 배치·구현 순서를 정의한다. [강 실험 비교 화면 배치도](docs/design/river-comparison-wireframe.svg)도 함께 참고한다.

## 현재 기준

- 공유 대화: https://chatgpt.com/share/6ab66deb-7c94-83e8-b285-261442955e18
- 확정된 화면 구조: 메인 다음 자연 스테이지 선택 화면만 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG. 캐릭터가 맵을 돌아다니다 특정 장소에 들어가면 해당 장소의 2D 활동 화면으로 전환한다. 나머지 화면은 기존 2D 게임 스타일.
- 화면 구조: 이후 심화 설계서의 **5개 미션 × 활동 2장 = 활동 10장**을 논의 기준으로 사용. 메인·선택 맵·최종 복구·엔딩·인증서는 별도.
- 기존 PRD/TRD/JSON은 이전 버전의 참고 자료다. 새 구현 명세로 그대로 사용하지 않는다.
- 사용자가 요청한 순서에 따라 시나리오 대화 후 PRD/TRD와 MVP를 구체화한다.
- 2026-10-12 공통 UI 확정: 모든 페이지 좌측 상단 홈·이전, 우측 상단 소리·설정. 설정은 섹션을 나누지 않는 단일 창이며 관리자 전체 해금 하나로 모든 페이지를 함께 연다. 상세 규칙 및 미확정 재미·3D 제안은 `docs/UI_AND_ENGAGEMENT.md` 참고.

## 원본 자료 검토 당시의 한계

- 원본 자료 검토 당시 실행 소스는 없었고 샘플 페이지는 PNG였다. 현재는 `src/`와 실행·빌드 스크립트가 있으며 위 최신 설계를 후속 구현 기준으로 사용한다.
- 배경에 학습 대상이 이미 합쳐진 경우가 있다. 학생 조작에 따라 변하는 물·흙·분출물 등을 별도 레이어로 준비해야 한다.
- 원본 자료에는 독립 캐릭터 시트·이동 스프라이트·픽셀아트 자연 선택 맵이 없었다. 현재 프로토타입 에셋은 `public/assets/`에서 확인한다.
- ZIP 샘플 10장은 일부 내부 이미지와 활동 제목이 맞지 않고 잘린 화면 조각을 사용한다. 최종 화면으로 그대로 쓰지 않는다.
- 교과 성취기준은 제공 설계서 기준이며 공식 교육과정 대조는 별도로 필요하다. 지진 행동의 후속 설계 기준과 확인한 공식 출처는 최신 설계의 안전 활동에 명시했다.
