# 07 움직이는 지오밸리 · 지도 악당 연계 계획

2026-11-14 · **초기 시안과 구현 계획 기록.** 이 문서는 구현 전 상태를 설명한다. 이후 지도에 적용된 대사와 동작은 `src/map-villain-rules.js`, `src/map-villains.js`와 운영 화면을 기준으로 확인한다. 공통 인수인계와 이미지 시안은 과학 콘텐츠 공동 작업 폴더에 보관돼 있다.

운영 대응: [콘텐츠](https://geovalley.pages.dev/) · [GitHub](https://github.com/yelmovie/changing-land-explorer). 작업을 다시 시작할 때 공식 운영 시트와 활성 지도 버전을 재확인한다.

## 외형과 등장

**돌먼지 대장 / 기존 캐릭터 실루엣, 층진 바위와 청록 물길.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

현재 roster의 river/volcano/rocks/city/safety와 연결. 기존 피해 룰과 새 피격 연출 분리. 57px 시안 기준의 출처.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 물길 관측소 | 바위를 물길에 밀어 넣기 | “물은 여기서 멈춰!” |
| 화산 연구소 | 가짜 분화 표지를 발로 차 올리기 | “이 표지판은 내 장난이지!” |
| 암석 공방 | 층진 돌을 비스듬히 포개기 | “맨 위 돌을 빼면 어쩔래?” |
| 기록탑 | 돌 표찰로 기록 앞을 가리기 | “이 기록은 잠깐 가려 둘게!” |
| 안전 훈련소 | 방향 표지 앞에 조약돌 쌓기 | “안내 표지는 안 보이게!” |

상황 대사 예시:

- 접근: “이 바위, 꿈쩍도 안 할걸!” / “돌 하나 더 올릴까?”
- 1·2타: “앗, 조약돌이 굴렀다!” / “내 바위가 움직여!”
- 퇴장: “먼지만 남기고 간다!” / “물길은 너희 차지야!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 돌 표면에 짧은 황토 충격점 |
| 2타 · 더 큰 반동 | 자갈이 두 방향으로 톡 |
| 3타 · 마무리와 퇴장 | 바위가 옆으로 구르고 황토 먼지만 남기고 악당 퇴장 |
| 주인공 접촉 | 주인공은 팔로 먼지를 가리고 짧게 미끄러짐 |
| 보조 캐릭터 접촉 | 동료는 낮게 움츠리고 한 번 털어냄 |
| 악당의 접촉 공격 동작 | 바위를 가슴 앞에 들어 올렸다가 한 발 내디딤. 접촉점 아래에서만 황토 먼지. |
| 타격·퇴장 효과음의 차이 | 탁 → 우두둑 → 사각 |
| 접촉 효과음 모티프 | ‘툭, 우두둑’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

공통 인수인계에서 정한 방향·시선 규칙을 적용한다. 바위와 물길은 지도에 고정하고 돌먼지 대장의 몸과 팔만 돌린다. 먼지는 해당 팔과 접촉 위치에서 나게 한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/map-villain-rules.js](../src/map-villain-rules.js) · [src/map-villains.js](../src/map-villains.js) · [src/map-combat-engine.js](../src/map-combat-engine.js) · [src/map-villains.css](../src/map-villains.css). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
