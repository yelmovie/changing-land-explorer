# 다섯 스테이지 반응형·학습 시각 고도화

2026-11-08. **확인한 다섯 화면 크기에서 글자/아이콘 겹침과 조작판 가림을 수정하고 재검증했다.** 대상은 현재 공유 작업본이다. `edu-design`으로 수정하고 `edu-final-check`의 반응형·터치·글자·학습 조작 범위를 점검했다. 이번 문서는 새로운 전체 배포 판정이나 학습 효과 측정이 아니다.

## 원인과 수정

| 실제 문제 | 수정 결과 |
|---|---|

큰 화면은 전체 배경·상단 질문·하단 안내 구성을 유지한다. 작은 화면의 조작 스크롤은 다음 버튼과 분리하며 실험 화면이나 페이지 전체를 스크롤시키지 않는다. 실제 배치 계약은 [설계 기록](../design/RESPONSIVE-STAGES-20261108.md)에 있다.

## 스테이지별 학습 표현

| 스테이지 | 학습자가 읽기 쉬워진 변화 |
|---|---|
| 물길 관측소 | 같은 대표 흙덩이가 언덕에서 깎여 나와 물과 이동하고 아래쪽 퇴적물에 정착하도록 연결. 물이 많은 조건의 운반량/크기 차이를 기존 재질로 표현. 기존 한 언덕·중립 빈 원·큰 이름표 선택 유지. |
| 화산 연구소 | 모형의 붉은 물은 차가운 액체 반사/물결, 주사기는 둥근 캡·금속 봉·벡터 화살표로 다듬음. 실제 용암의 느린 피막, 암석의 중력 궤적, 재의 바람/낙하를 분리하고 선택한 분출물만 은은하게 강조. |
| 암석 공방 | 왼쪽 초점과 오른쪽 실제 질감 확대창을 연결하고 렌즈 테두리·반사·배율 설명 정돈. 관찰 그림을 가리던 장식 캐릭터를 숨기고 주문 카드의 근거/행동 문구를 분리. |
| 시간 관측소 | 회색 구름 타원 대신 기존 화산재 이미지를 재사용하고 평면 차단 표시를 목재 차단대로 변경. 농장은 밭 모양에 맞춘 덮임과 ‘아주 오랜 시간 뒤’를 유지. 시간 분할선에 설명이 잘리는 표현 제거. |
| 안전 훈련소 | 학습자가 위험 표식을 놓은 뒤 해당 공간을 강조. 책상 다리 잡기/흔들림/멈춤 피드백을 실제 대기 상태와 맞춤. 길의 방향과 걸은 구간은 학습자가 그린 경로 위에서만 표시. |

새 정답 위치·정답 이름을 미리 표시하지 않았고, 저장·완료·보상·기존 폰 대체 조작을 보존했다. 모션은 이해를 돕는 일러스트이며 실제 분출 속도나 침식량을 계산하는 물리 모형은 아니다. 모션 감소·일시정지·장면 종료 정리를 유지한다. 원본 그림·음성·Claude의 이전 변경은 보존했고 새로운 이미지 생성이나 의존성 설치는 하지 않았다.

## 실제 검증

- 화면 크기: **1280×800,1024×768,915×412,667×375,1920×1080**. 30개 단계·힌트·개념·공통 화면 **450/450**, 런타임 오류0. 수정 전 네 크기360/360도 통과했던 기존 DOM 검사만 믿지 않고 별도 겹침 계측과 캡처를 추가했다.

- 정상 모션13개 프레임 및 상태 조작12개 장면을 캡처해 직접 확인. 강의 두 물 조건·모형/실제 화산·암석1/3초점·도시 전후/안내판·안전 잡기/멈춤/걷기를 포함.

## 수정 범위·한계

공통 배치는 주 작업자만, 자연 단계와 나머지 세 단계는 파일을 나눠 병렬로 작업했다. 브라우저는 한 검수 담당자가 맡았다. 최종 변경은 `src/rounded-ui.css`, `src/adventure/index.js`, `src/main.js`, `src/stage-art.js`, `src/observation-scenes.js`, `src/river-water.js`, `src/volcano-motion.js`, 다섯 단계 모듈 중 화산/암석/도시/안전이다. `src/adventure/river.js`는 이번에 수정하지 않았다.

실제 iPad/학교 Android·전자칠판에서의 손가락 편의성·노치·Safari·스피커 지연과 학생 학습 효과는 이번 헤드리스 검사의 범위 밖이다. 작은 화면에서는 일부 그림 속 보조 글자가 작고 긴 안내/조작 칸은 내부 스크롤을 사용한다. 모든 기기의 모든 글자를 전수 보장한다고 표현하지 않는다. 이번 범위의 완료는 재현한 겹침/가림 수정과 위 조작·시각·저장 검증이며, 공개 배포는 하지 않았다.
