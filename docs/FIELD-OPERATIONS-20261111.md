# 관찰을 현장 문제 해결로 연결하는 7번 리팩토링

## 보존
기존 5지역·10탐구·30발견·에셋·개념 영상·저장 키를 보존한다. 각 지역의 두 번째 탐구를 마치면 현장 작전으로 연결하고 성공 뒤 기존 도구 보상과 지도 진행으로 돌아간다. 기존 완료 기록은 취소하지 않는다. 현장 작전은 `drafts[id].data.fieldOperation`에 저장하며 학생/교사 기록 분리를 유지한다.

## 목표와 미션
- 강 [4과11-01]: 침식·운반·퇴적 흔적을 모두 살펴본 뒤 다리 위치를 선택하고 모형의 물을 흘려 시험·수정한다. 점검된 받침에 연결해 리버가 건넌다. 실제 다리의 안전은 이 모형으로 판정할 수 없고 전문가 점검이 필요함을 표시한다.
- 화산 [4과11-02/04]: 위험 표시와 안내된 통로를 따라 관측소에 소식을 전달한다. 실제 경로는 공식 안내를 따른다.
- 암석 [4과11-03]: 색과 알갱이 두 근거를 비교한 뒤 두 주문에 맞는 현무암/화강암 표본을 배송한다. 그림은 대표 표본이다.
- 도시 [4과11-04]: 화산재 소식에 창문·주민 활동·안내판의 상태를 바꾸고 행동 결과를 확인한다.
- 안전 [4과11-04]: 몸 보호→책상 다리 잡고 기다림→멈춤 확인→선생님과 집합의 순서를 적용한다. 기존 직접 걷기 대피의 하트 소진 제한을 제거해 안전 행동을 속도로 판정하지 않는다.

## 구현과 한계
DOM이 조작·알림·레이아웃을 소유하고 기존 Phaser 실험은 그대로 유지한다. 선택→화면 상태 변화→시도→피드백→수정→결과 흐름이다. 전면 자유이동 RPG나 모든 실험의 전면 교체는 아니다. 새 현장 미션은 5개이며 기존 학습 활동을 마친 뒤 연결하는 1차 게임화 구현이다. 교과 이해의 실증 효과는 교실 검증 전이다.

## 안전 근거
기존 `docs/reviews/CURRICULUM-CHECK-20261102.md`의 교육부 교육과정·행정안전부 지진/화산재 행동요령을 유지한다. 실제 안전 판정·재난 예측 모형이 아니다. 공포·강한 흔들림·시간제한을 사용하지 않는다.

2026-11-11 공식 지진·화산재 행동요령 페이지를 재열람했다. 책상 아래 몸 보호·계단 대피·재난 안내 확인, 화산재 낙하 중 실내 대기를 반영했다. 화산 현장 작전의 마지막은 대피소 밖으로 다시 이동하는 것이 아니라 안에서 관측소에 소식을 보내는 행동이다.
