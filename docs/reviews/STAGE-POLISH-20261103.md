## 수정

- 공통 관찰 순회: 한 바퀴 후 정지, 완료 뒤 다시 재생, 중간 이동 정지 후 같은 지점 이어보기.
- 주사기: 정지 후 물 흐름이 계속 증가하던 문제 수정. 저장 진행과 완료 후 시각 재생을 분리. 매 프레임 모형 이미지를 파괴·재생성하지 않고 고정 장치와 물 그래픽 재사용.
- 화산: 생성한 화산재 구름 3개 텍스처와 재사용 입자 풀. 경사면 용암 반사, 떨어지는 고체 조각. 모형의 차가운 붉은 물은 용암 발광과 구분.
- 암석: 고해상도 현무암·화강암, 비율을 유지한 표본/2.4배 확대, 650ms 돋보기 이동. 완료 뒤 관찰 중복 기록·보상 차단.
- 시간 비교: 900ms 이동, 두 시기 관찰 뒤에도 다시 보기 가능. 답 카드 연결과 분리. 아래 슬라이더의 중복 제목을 숨겨 장면 위 겹침 감소(접근성 이름 유지).
- 안전: 학생이 그린 검증된 길만 걷기·정지·이어보기·완료 후 다시 걷기. 경로 생성과 정답 선택은 자동화하지 않음.
- 움직임 줄이기 설정: 돋보기/시간 이동은 즉시 전환, 화산 장식 움직임 중단. 모달·탭 비활성·장면 종료 시 재생 정리.
