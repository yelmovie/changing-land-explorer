# 실험과 조작을 한 화면에 배치

사용자 요청: 모든 스테이지의 실험과 조작을 스크롤 없이 함께 보고, 반복 안내를 줄이며, 정답 판단을 제외한 관찰·반복 조작에 속도 선택 자동재생을 제공한다.

- 기존 Phaser 3.90, 1200×640 좌표, 학습 판정과 학생 저장 형식을 유지한다.
- 충분한 높이에서는 하단 조작, 낮은 가로 화면에서는 오른쪽 조작을 사용한다. 조작 칸 내부 스크롤도 없앤다. 실험 영역은 나머지 공간을 채운다.
- 힌트·수첩·개념 영상·획득 도구는 상단의 ‘도구’ 메뉴로 모은다. 단계 이름 반복은 없애고 번호·완료 표시와 단계 목록을 유지한다.
- 안내는 현재 행동 한 문장, 진행 수는 한 곳에 표시한다. 완료 뒤에는 다음 버튼을 강조한다.
- 자동재생은 기존 18개 관찰·조작 단계에 제공한다. 0.5/1/2/3배속은 방문 간격과 실험 움직임에 함께 적용한다. 재생 중 속도 변경은 이어서 적용하고, 직접 조작·모달·창 비활성화·단계 이동은 재생을 멈춘다.
- 카드 정답·분류·안전한 위치·대피 경로는 사용자가 판단한다. 자동재생으로 다음 페이지를 넘기거나 판단을 대신하지 않는다.
- 실제 브라우저로 667×375, 915×412, 1024×768, 1280×800, 1920×1080의 30장면 및 재생·중단·배속·수동 선택·저장 복원을 확인한다. 임시 프로필·캐시·결과는 외장 SSD에 둔다.
