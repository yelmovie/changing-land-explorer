# 7 earthchange · 시리즈 고도화 적용 보고

2026-11-07. 현재 프로젝트의 기존 미커밋 개선을 보존한 증분 작업이다. 기존의 물결·퇴적 텍스처, 암석 주문 활동, 저장 복구, 모모 음성 및 반응형 개선을 이번 작업이 새로 만든 것으로 계산하지 않았다. 원본 임시 파일을 영구 삭제하지 않았고 1~5 및 다른 프로젝트는 수정하지 않았다. 커밋·푸시·외부 배포 없음.

## 반영한 개선

1. **힌트 기록 정확성**: 기존에는 첫 관찰 질문만 열어도 `answerHint=true`였다. `src/adventure/hints.js:27–42`에 90개 문구의 관찰(o)/조작(g)/정답(a) 분류를 추가하고 `src/adventure/index.js:135–141,220–226`에서 실제 본 종류와 최대 단계만 저장한다. 관찰·조작 도움으로 정답 제공을 표시하지 않는다. 이미 정답을 본 기록은 후속 일반 힌트나 재접속으로 지우지 않는다. `src/explore-ui.js:39`의 기록 표지도 구분한다. 심각도: 중간, 학습 기록 해석 오류. 순수 함수와 실제 브라우저에서 재현·해결 확인.
2. **교사 학습 근거**: `src/learning-guide.js`에 다섯 장소·열 활동의 목표/조작/증거/기준/적용/모형 한계를 구조화하고 설정의 교사용 안내에 연결했다(`src/main.js`). 완료·보상을 독립 성취로 오해하지 않도록 안내한다. 기준 일치·누락 검사를 추가했다. 교사 가이드 펼침 행은 48px 이상, 포커스 표시는 `src/rounded-ui.css`에 추가했다.
3. **소리 선택권과 충돌 방지**: `src/audio-settings.js`에서 효과음과 주민 음성 각각 0~100 조절 및 저장. 기존 BGM 조절과 전체 mute는 유지한다. `src/sound.js`에서 현재 및 예약 효과음 취소, 음성 재생 중 음악 보류, 종료·실패·교체·음량0·탭숨김·화면전환 정리를 적용했다. 이전 음성의 지연 실패가 새 음성을 끊지 않고, 외부 연출의 음악 보류도 해제하지 않는다. 음량을 다시 올려도 종료한 음성을 자동 재생하지 않는다.
4. **자산 재사용**: 기존 생성 텍스처와 주민 모모 음성25개, 효과음을 확인했다. `scripts/voices.json`에 원본·성우·대사가 있어 그대로 재사용한다. 음성25개 HTTP 응답과 비어 있지 않음을 검사했다. 신규 이미지/음성 생성 및 원본 삭제 없음. 실제 스피커 음질/지연 합격을 주장하지 않는다.

## 단계 간 중복·흥미·성취 점검

| 장소 | 첫 활동의 역할 | 둘째 활동의 역할 | 적용·중복 판단 |
