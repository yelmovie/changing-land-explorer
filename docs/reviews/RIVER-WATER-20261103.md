# 물길 실험 자동재생·시각 표현 개선 — 2026-11-03

## 적용
- 우측 상단 자동재생/일시정지. 예상 깃발을 직접 놓기 전에는 숨기고, 첫 실험·두 번째 실험 완료 후에는 다시 재생 가능.
- 완료 후 재관찰은 화면 상태만 바꾸며 예상, 관찰 기록, 보상, 완료 상태를 다시 저장하지 않음.
- 모달/직접 조작/화면 전환 시 자동재생 중지. 일시정지 후 이어보기.
- 물뿌리개 기울기, 분리된 물줄기, 낙하·물튀김, 젖은 흙, 흙 알갱이의 이동, 아래쪽에 서서히 넓어지는 퇴적 모래.
- 같은 흙 언덕·경로·재생 시간에서 물의 양을 비교. 자동재생은 답이나 흔적 이름표를 선택하지 않음.
- 두 실험 비교·수첩도 공통 장면 데이터와 새 에셋을 사용.
- 예상 깃발은 지점을 선과 원으로 가리켜 퇴적 부분을 덜 가리고, 실험 후 물뿌리개는 원위치로 복귀.
