## 2. 교육과정 핵심 분석

### [4과11-01]
흐르는 물의 작용과 강 주변 지형의 특징을 관련지을 수 있다.

반영:
- 물을 직접 흘려 침식·운반·퇴적 현상을 관찰
- 상류·하류 특징을 여러 증거로 판단
- TIME SCAN으로 실험 전·중·후 비교

### [4과11-02]
화산의 의미와 화산 활동으로 나오는 물질을 알고, 화산 활동을 모형으로 표현할 수 있다.

반영:
- 화산 활동 모형 구성
- 분출 과정 관찰
- 화산재·화산 암석 조각·용암·화산 가스 관찰
- 실제 화산과 모형의 공통점·차이점 비교

### [4과11-03]
화성암을 관찰하고 분류할 수 있다.

반영:
- 현무암·화강암만 다룸
- 3D 암석 회전·확대·비교
- 색·알갱이 크기 중심 복합 증거 제출
- 구멍 하나만으로 현무암을 판별하는 단순 규칙 금지

### [4과11-04]
화산 활동과 지진이 우리 생활에 미치는 영향을 조사하여, 대처 방법을 실천할 수 있다.

반영:
- 화산 영향은 시간 변화에 따라 피해와 이로움을 조사
- 지진은 장소별·상황별 행동 순서 실천
- 지진 발생 원인·판 구조론은 다루지 않음

## 3. 메인 퀘스트

### WORLD INCIDENT — 지오밸리 변화 기록 오류

강, 협곡, 화산지대, 암석 연구소, 화산도시, 안전센터로 이루어진 지오밸리에서 변화 기록 시스템에 이상 신호가 발생한다.

- 강 주변 지형 변화 기록 누락
- 화산 모형과 실제 화산 자료 혼선
- 암석 표본 분류 정보 소실
- 화산도시 영향 기록 오류
- 지진 대응 행동 데이터 누락

학생은 **지오밸리 변화 조사원**으로 임명된다.

### 최종 목표

5개 Mission을 완료해 Evidence 5종을 확보하고, 마지막에 Geo Core에 연구 결과를 입력하여 지오밸리 변화 기록 시스템을 복구한다.

# 6. Mission 1 — 물이 남긴 흔적

## 학습목표
흐르는 물의 작용과 강 주변 지형의 특징을 여러 증거를 근거로 관련짓는다.

## Micro Loop
```text
예상핀 배치
→ 물 흘리기
→ 지형 변화
→ TIME SCAN
→ 증거 표시
→ 판단
→ 부족한 증거 발견
→ 다시 관찰
→ Evidence 획득
```

## Evidence
**강 변화 조사 기록**

## World Change
강 구역 관측선이 청록색으로 복구되고 경고 아이콘이 해제된다.

# 11. 총 10개 Core Screens

> 각 Mission당 2장, 총 10장. 메인·관측본부·Final Report·Final Movie·Certificate는 별도 Meta Screen.

## SCREEN 01 — 흐르는 물 실험실

- **목적:** 침식·운반·퇴적을 용어 암기 전에 현상으로 경험
- **조작:** Drag / 3D Rotate / Slider / Timeline Scrub / Evidence Pin
- **학생 행동:** 예상핀 → 물 흘리기 → 전·중·후 비교 → 깎인 곳·이동 흔적·쌓인 곳 표시
- **화면 반응:** terrain morph, 물 경로, 흙 입자 이동, 시간 상태 전환
- **재시도:** TIME SCAN으로 다시 비교하고 핀 이동
- **성공 조건:** 침식·운반·퇴적 증거 각각 1개 이상
- **3D:** 핵심 3D

## SCREEN 02 — 강의 흔적 판독실

- **목적:** 상류·하류 특징을 여러 증거로 관련짓기
- **조작:** Swipe / Zoom / Evidence Select / Connector
- **학생 행동:** 상류→하류 이동, 관측 지점 최소 4개 조사
- **핵심 규칙:** 증거 2개 이상 모아야 판단 가능
- **3D:** 2.5D

## SCREEN 03 — 화산 모형 구성실

- **목적:** 화산 활동 모형 표현과 분출 관찰
- **조작:** Object Placement / Toggle / Playback / 3D Rotate
- **학생 행동:** 모형 구성 → 예상 → 분출 → 속도 조절 → 관찰
- **3D:** 핵심 3D

## SCREEN 04 — 모형과 실제 화산 비교실

- **목적:** 모형과 실제의 공통점·차이점 비교
- **조작:** Split View / Pause / Zoom / Connector Draw
- **성공 조건:** 공통점 2개 + 차이점 2개
- **3D:** 부분 3D + 비교 UI

## SCREEN 05 — 암석 3D 관찰실

- **목적:** 실제 표본처럼 암석 여러 방향 관찰
- **조작:** Rotate / Pinch Zoom / Compare Tray / Observation Pin
- **가드레일:** 구멍 하나만으로 현무암 판단 금지
- **3D:** 핵심 3D Object Viewer

## SCREEN 06 — 암석 감정 증거판

- **목적:** 정답보다 분류 근거 제출
- **조작:** Select / Evidence Link / Compare / Submit
- **성공 조건:** 현무암·화강암 분류 + 근거 2개씩
- **3D:** Object Viewer + DOM Evidence UI

## SCREEN 07 — 시간이 흐르는 화산도시

- **목적:** 시간에 따른 화산 영향 변화 조사
- **조작:** Timeline Slider / Location Hotspot / Before-After / Impact Link
- **핵심:** “화산 = 나쁨” 식 단순화 금지
- **3D:** 2.5D

## SCREEN 08 — 화산 관측센터

- **목적:** 여러 자료를 근거로 생활 영향과 안전 정보 정리
- **조작:** Map Tap / Layer On-Off / Evidence Connector / Priority Drag
- **성공 조건:** 서로 다른 자료 2개 이상 근거 연결
- **3D:** 없음

## SCREEN 09 — 지진 대응: 흔들리는 중

- **목적:** 현재 장소와 상황 단계에 맞는 몸 보호
- **조작:** Character Move / Tap / Optional Long Press / Action Sequence
- **핵심:** ‘장소’와 ‘흔들리는 중인지’를 함께 판단
- **3D:** 2.5D

## SCREEN 10 — 지진 대응: 흔들림이 멈춘 뒤

- **목적:** 실제 대피 경로 판단
- **조작:** Path Drawing / Undo / Hazard Avoidance / Safe Zone
- **반응:** 경로가 위험 구역을 통과하면 해당 위험 구간만 시각 강조
- **3D:** 2.5D

# 22. 전자칠판 대응

# 28. 최종 완료 조건

- 초등 4학년 교육과정 범위를 벗어나지 않는다.
- 유치원 수준의 단순 맞추기 게임이 아니다.
- 10개 Core Screen에서 동일 조작을 반복하지 않는다.
- 모든 Mission에 Micro Loop가 있다.
- 모든 Mission에서 Evidence가 남는다.
- Mission 성공이 Map/World에 시각적으로 반영된다.
- NPC가 학습 진행에 실제 역할을 한다.
- Final Mission에서 학생이 직접 마지막 복구 행동을 한다.
- Final Movie가 처음과 마지막 세계의 차이를 보여준다.
- 전자칠판에서도 핵심 정보가 읽힌다.
- 태블릿 사용 이유가 각 화면에서 명확하다.
- 캐릭터는 부엉이·로봇이 아니며 장식용이 아니다.
- 화성암은 현무암·화강암만 평가한다.
- 지진 발생 원인을 핵심 학습으로 다루지 않는다.
- 현무암의 구멍을 절대적 판별 규칙으로 사용하지 않는다.
- 과학적 정확성을 게임 연출보다 우선한다.
