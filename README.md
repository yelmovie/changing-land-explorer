## 실행과 검증

Node.js 20 이상에서 별도 패키지 설치 없이 실행한다.

```sh
npm run dev      # http://localhost:5177
npm run check    # JavaScript 문법 검사
npm test         # 학습·저장·진행 규칙 회귀 검사
npm run build    # dist/ 정적 빌드
PORT=5197 npm run preview  # http://localhost:5197 에서 빌드 확인
```

개발 화면과 빌드 미리보기는 포트를 나눠 서비스워커 캐시가 섞이지 않게 한다. 두 주소의 학생 기록도 별도로 저장된다. 빌드 화면은 온라인에서 문서·코드를 먼저 갱신하고, 오프라인에서는 저장된 자료를 사용한다.

선택 검증: `npm run check:layout`(1024×768·1280×720·1920×1080 화면·팝업·재생), `npm run check:flow`(학생 모드 30개 발견→10개 영상→5개 보상→저장 복귀). 실행 중인 개발 서버와 Playwright + Chrome이 필요해. 기존 설치를 재사용할 때는 `PLAYWRIGHT_PATH`를 패키지의 `index.mjs` 절대 경로로 지정하면 돼. 격리된 브라우저에서 검사하고 결과는 `.work/learning-verification/`에 저장해.

지도 키보드 회귀 검사는 `npm run check:keyboard`로 실행한다. 버튼을 누른 뒤 방향키·WASD 이동, 팝업 포커스, 길게 누르기, 움직임 줄이기와 엔진 실패 대체 동작을 실제 브라우저에서 확인한다. 위 Playwright 설정을 동일하게 사용한다.

영상 재제작은 `npm run concepts:render`를 사용해. FFmpeg·Sharp 제작 도구의 경로는 `FFMPEG_PATH`·`SHARP_PATH`로 지정할 수 있어. 앱 실행에는 제작 도구가 필요 없어.

실행 에셋과 Phaser 3.90.0은 `public/assets/`에 포함한다. 이미지 재가공 스크립트는 제작 당시의 로컬 원본·Sharp 경로를 사용하며 앱 실행과 빌드에는 필요하지 않다. 원본 이미지·ZIP·중간 백업과 `dist/`는 Git에 넣지 않고 기존 로컬 폴더에 보존한다.

저장소: https://github.com/yelmovie/changing-land-explorer

탐구 설계 배경: [태블릿 탐구 경험 설계](docs/TABLET_EXPLORATION_DESIGN.md). 10개 활동의 조작·피드백·개인 증거·완료 조건·화면 배치·구현 순서를 정의한다. [강 실험 비교 화면 배치도](docs/design/river-comparison-wireframe.svg)도 함께 참고한다.

## 현재 기준

- 공유 대화: https://chatgpt.com/share/6ab66deb-7c94-83e8-b285-261442955e18
- 확정된 화면 구조: 메인 다음 자연 스테이지 선택 화면만 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG. 캐릭터가 맵을 돌아다니다 특정 장소에 들어가면 해당 장소의 2D 활동 화면으로 전환한다. 나머지 화면은 기존 2D 게임 스타일.
- 화면 구조: 이후 심화 설계서의 **5개 미션 × 활동 2장 = 활동 10장**을 논의 기준으로 사용. 메인·선택 맵·최종 복구·엔딩·인증서는 별도.
- 기존 PRD/TRD/JSON은 이전 버전의 참고 자료다. 새 구현 명세로 그대로 사용하지 않는다.
- 사용자가 요청한 순서에 따라 시나리오 대화 후 PRD/TRD와 MVP를 구체화한다.
- 2026-10-12 공통 UI 확정: 모든 페이지 좌측 상단 홈·이전, 우측 상단 소리·설정. 설정은 섹션을 나누지 않는 단일 창이며 관리자 전체 해금 하나로 모든 페이지를 함께 연다. 상세 규칙 및 미확정 재미·3D 제안은 `docs/UI_AND_ENGAGEMENT.md` 참고.

## 원본 자료 검토 당시의 한계

- 원본 자료 검토 당시 실행 소스는 없었고 샘플 페이지는 PNG였다. 현재는 `src/`와 실행·빌드 스크립트가 있으며 위 최신 설계를 후속 구현 기준으로 사용한다.
- 배경에 학습 대상이 이미 합쳐진 경우가 있다. 학생 조작에 따라 변하는 물·흙·분출물 등을 별도 레이어로 준비해야 한다.
- 원본 자료에는 독립 캐릭터 시트·이동 스프라이트·픽셀아트 자연 선택 맵이 없었다. 현재 프로토타입 에셋은 `public/assets/`에서 확인한다.
- ZIP 샘플 10장은 일부 내부 이미지와 활동 제목이 맞지 않고 잘린 화면 조각을 사용한다. 최종 화면으로 그대로 쓰지 않는다.
- 2022 개정 과학과 교육과정 원문과 실제 구현을 대조한 결과는 [땅의 변화 교육과정·내용 점검](docs/reviews/CURRICULUM-CHECK-20261102.md)에 정리했다.

2026-11-08 활동 화면 정리: 실험과 조작은 페이지·조작 칸 스크롤 없이 함께 표시해. 낮은 가로 화면은 오른쪽 도크를 사용하고, 긴 발견 설명은 전체 너비로 펼쳐. 힌트·관찰 수첩·개념 영상·3D 보조 도구는 상단 ‘도구’에 모았어. 자동 관찰은 0.5/1/2/3배속으로 방문 간격과 움직임을 함께 바꾸며, 정답·분류·경로 선택은 직접 해. 현재 할 버튼 하나를 강조하고 완료하면 다음 버튼을 강조해.

추가 검증: `npm run check:activity`는 30개 장면 × 5크기의 화면·패널 스크롤, 조작 가림, 터치 크기를 확인해. `CHECK_COMPLETED_STATE`에 `check:flow`가 생성한 `flow-finished-state.json`을 지정하면 실제 완료 기록으로 재방문 화면을 검사해. `npm run check:playback`은 브라우저에서 배속·중단·재생 중 속도 변경·정답 분리·저장 복원을 확인해. 위와 같은 Playwright/개발 서버 환경을 사용하며 결과는 `.work/activity-fit-20261108/`에 저장해.



### 2026-11-12 납품 검수

현장 작전은 낮은 가로 화면에서 장면과 안내·조작을 좌우로 배치한다. 강의 흔적과 암석 특징은 자동 관찰의 0.5·1·2·3배 속도를 선택할 수 있으며, 판단이 필요한 단계에서 멈춘다. 인증서는 문서와 인쇄·돌아가기 조작 영역을 나눈다.

`npm run check:operations`는 Playwright가 준비된 환경에서 다섯 현장 작전의 상태별 화면 맞춤과 자동 관찰의 판단 전 정지를 확인한다. `npm run check:voices`는 다섯 장소의 도착 대사·실제 음성 재생·닫기 시 정지와 안내 음성 27개의 디코딩을 검사한다. `PLAYWRIGHT_PATH`, `CHECK_URL`, `CHECK_OUT`으로 실행 환경을 지정한다. 최종 판정과 점수는 `docs/reviews/RELEASE-REVIEW-20261112.md`와 `docs/reviews/SCORE-20261112.md`를 참고한다.
