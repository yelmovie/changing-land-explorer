# 배경 중심 반투명 UI · 2026-11-11

## 변경
- 공통 탐색 아이콘, 제목·안내 패널, 조작 버튼을 반투명 유리 재질로 통일. 콘텐츠 자체의 opacity는 낮추지 않음.
- 두꺼운 갈색 테두리와 돌출 그림자를 줄이고 읽기 창은 90% 밝은 배경으로 가독성을 유지.
- 설정·힌트 창 주변의 어두운 덮개를 옅게 바꾸어 배경을 보존.
- 지도 HUD를 별도 레인에 배치하고 팬 이동 중 고정 UI에 가려진 지도 타깃의 상호작용 표면을 조정.
- 작은 가로 화면 암석 주문 제목과 표본 카드의 교차 수정.

## 검증
- JavaScript 문법 검사 및 150 단위·회귀 테스트 통과.
- 1280×800 실제 포인터 흐름: 30개 발견, 10개 개념 연결, 5개 보상, 마지막 3개 도전, 엔딩·인증서·새로고침 저장 복귀 통과.
- 지도 키보드 7종: 버튼 후 방향키, 설정 닫기/WASD, 길게 누르기, 대화 포커스, 수정키, 모션 감소, Phaser 대체 경로 통과.
- 실제 브라우저에서 강·암석·설정 화면 재질과 가독성 확인.

실물 태블릿은 시험하지 않았으며 자동 검사에서 상태를 직접 불러오는 경우는 자연 플레이 완주와 구분한다.

## 추가 수정·검증
- 장소와 주민 이름표를 HUD와 다른 버튼을 피하는 가까운 여백에 재배치. 작은 화면의 주민 접근은 대화 목록에서도 가능.
- 인증서 인쇄 버튼은 문서 아래 정상 흐름에 배치. 낮은 화면에서는 문서를 스크롤해 인쇄 버튼에 접근한다.
- 지도 25케이스(5해상도 학생/교사·일반/전체보기 및 주민목록): 정적 버튼 겹침 0, 전체보기 다섯 장소·기록탑 중앙 터치 가능.
- 움직이는 악당은 고정 UI·라벨을 가리지 않도록 가림 처리하되 악당 찾기/키보드 접근은 유지한다.
- 실물 기기 성능·모든 OS 브라우저 조합은 미검증.
- 최종 전투 7종과 키보드 7종 재검 통과.
- 활동 150상태의 버튼 가림·텍스트 교차·캔버스/HUD 교차 0, 공통 화면 55/55 통과. 기존 전체450 검사 중 활동·힌트·개념400건 통과, 발견된 공통 화면 오류는 최종 공통55 및 지도25 재검으로 확인.
