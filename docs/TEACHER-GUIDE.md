# 교사용 안내 · 움직이는 지오밸리

## 1. 한 줄 소개

리버와 함께 강·화산·암석·도시·안전길 다섯 장소를 탐험하며 땅의 변화를 관찰하고, 다섯 탐험 도구를 모아 기록탑에 불을 켜는 과학 탐구 게임입니다.

## 2. 대상

| 항목 | 내용 |
|---|---|
| 학년·학기 | 초등 4학년 1학기(운영 시트 「이예리 선생님」 탭, 2026-11-22 확인) |
| 과목·단원 | 과학 「땅의 변화」(운영 시트 단원명). 교과서별 단원 번호는 학교 교과서로 한 번 더 확인 필요. |
| 성취기준 | [4과11-01] 흐르는 물의 작용과 강 주변 지형의 특징을 관련지을 수 있다. (강) |
| | [4과11-02] 화산의 의미와 화산 활동으로 나오는 물질을 알고, 화산 활동을 모형으로 표현할 수 있다. (화산) |
| | [4과11-03] 화성암을 관찰하고 분류할 수 있다. (암석) |
| | [4과11-04] 화산 활동과 지진이 우리 생활에 미치는 영향을 조사하여, 대처 방법을 실천할 수 있다. (도시·안전) |

## 3. 준비

- 기기: 태블릿, 전자칠판, PC. 폰 가로 화면과 폴드도 확인했습니다.
- 확인한 화면 크기: 1024×768, 1280×720, 1280×800, 1920×1080, 폰 가로 844×390.
- 소리: 리버·주민 목소리, 배경 음악, 효과음이 있습니다. 설정에서 크기를 조절합니다.
- 인터넷: 처음 한 번은 온라인으로 엽니다. 활동 자료가 저장된 뒤에는 연결이 끊겨도 지도와 10개 활동을 진행할 수 있습니다. 영상과 배경 음악은 온라인 연결을 권장합니다.
- 예상 시간: 40분 수업 한 번으로 시험하는 것이 계획이며 아직 하지 않았습니다. 확인 필요.

## 4. 차시 흐름

시작 이야기(인트로 영상 「강가에 남은 단서」) → 지도에서 장소 선택 → 장소마다 활동 1 → 개념 영상 → 활동 2 → 개념 영상 → 현장 임무 → 기록탑 → 엔딩 영상 → 인증서.

| 장소 | 활동과 학생이 하는 일 | 배우는 개념 |
|---|---|---|
| 강 (물길 관측소) | 물 흘리기, 물의 양 비교, 이름표 놓기. 상류·하류 탐사와 강 지도 완성. 현장 임무에서 조사 다리 놓기 | 침식·운반·퇴적, 상류와 하류의 차이 |
| 화산 (화산 연구소) | 모형 조립, 붉은 물 흘리기, 흐른 길 잇기. 분출물 살펴보기, 모형과 실제 화산의 같은 점·다른 점 연결 | 분출물, 모형과 실제 화산의 차이 |
| 암석 (암석 공방) | 표본 닦기, 어두운 돌·밝은 돌 확대 관찰. 주문에 맞게 표본 보내기, 새 돌 C·D 분류 | 색과 알갱이로 현무암·화강암 구분 |
| 도시 (시간 관측소) | 공항·농장·온천의 분출 당시와 이후 비교. 주민 안내판 채우기. 화산재 안내소 운영 | 화산 활동이 생활에 주는 영향의 변화 |
| 안전 (안전 훈련소) | 위험 찾기, 책상 아래로 몸 보호, 안전한 길 찾아 대피. 현장 임무 4단계 | 지진 때 몸 보호와 안전한 이동 |

장소마다 발견 6개(활동 2개 × 3단계), 개념 영상 2편입니다. 도시·강·화산·안전에는 현장 임무가 있고 암석에는 없습니다. 지도에서는 탐험을 마친 장소의 돌먼지 대장을 세 번 눌러 물리치면 성취 카드를 받습니다. 다섯 장소와 기록탑을 모두 마치면 엔딩과 인증서가 열립니다.

## 5. 정답과 판정 기준

관찰·조작 단계는 정답 없이 끝까지 하면 통과합니다. 고르거나 놓는 단계의 정답은 다음과 같습니다.

| 활동 | 정답 또는 통과 조건 |
|---|---|
| 강 1-3 | 깎여요 → 언덕 위 깎인 곳, 옮겨져요 → 가운데, 쌓여요 → 아래. 물에 옮겨진 흙은 언덕 아래쪽에 쌓임 |
| 강 2-3 | 상류: 크고 각진 바위 / 좁고 경사가 급한 물길. 하류: 넓고 완만한 물길 / 모래와 고운 흙이 쌓임. 깃발은 모래톱 |
| 강 현장 임무 2 | 다리 받침은 「점검한 양쪽 받침」 자리 |
| 화산 1-1 | 쟁반 → 산 모형 → 붉은 물 주사기 순서 |
| 화산 1-3 | 붉은 물이 나온 곳은 「2번 꼭대기 구멍」. 흐른 길은 꼭대기 1번부터 차례로 |
| 화산 2-2·2-3 | 같은 점(나오는 곳·흐르는 길 등)과 다른 점(뜨거운 용암, 함께 나오는 것 등) 카드를 알맞은 줄에 놓기 |
| 화산 현장 임무 | 용암을 피해 안내된 통로로 / 화산재를 피해 지정 대피소로 / 실제 화산은 뜨거운 물질도 나와 |
| 암석 1-2·1-3 | 표본 A: 전체가 어두운 색 + 알갱이가 잘 안 보임. 표본 B: 전체가 밝은 색 + 알갱이가 뚜렷함 |
| 암석 2-1~2-3 | 화강암 주문 ← 표본 B, 현무암 주문 ← 표본 A. 새 돌 C는 현무암 표본함, 새 돌 D는 화강암 표본함 |
| 도시 1-1~1-3 | 분출 당시 칸: 비행 중단 / 농작물 피해 / 출입 금지. 이후 칸: 다시 운항 / 오랜 뒤 토양 변화 / 안전 뒤 이용. 나머지 카드는 놓지 않음 |
| 도시 2-1~2-3 | 운항 안내를 확인해요(→ 창문 닫기 → 마스크로 코와 입 가리기) / 밭을 복구하고 기다려요 / 안전 안내 뒤 온천을 이용해요 |
| 도시 현장 임무 | 창문 닫기 / 실내에서 안내 기다리기 / 선생님과 확인한 재난 안내 |
| 안전 1-1~1-3 | 위험 표시는 창문·책장. 책상 아래로 옮긴 뒤 머리 보호. 책상 다리를 잡고 흔들림이 멈춘 뒤 확인 |
| 안전 2-1~2-3 | 위험 구역을 피해 출구를 지나 운동장(또는 공터)에 도착 |
| 안전 현장 임무 | 책상 아래 몸 보호 / 책상 다리 잡고 기다리기 / 멈춤 확인 후 선생님 따라 / 계단을 이용해 넓은 곳으로 |

틀리면 오답 문장과 단계별 힌트가 나오고, 다시 고를 수 있습니다.

## 6. 수업 팁

- 막히는 곳: 도시 활동의 힌트 문구가 화면의 버튼·칸과 다르게 읽힐 수 있습니다. 안전 활동의 「여진」은 설명 없이 나옵니다. 교사 검토표에서 「확인 필요」로 표시한 곳입니다.
- 되묻기: 「이 흙은 어디서 깎여서 어디에 쌓였을까?」 「모형과 실제 화산은 무엇이 같고 무엇이 다를까?」 「이 돌은 색과 알갱이 중 무엇을 보고 이름을 붙였을까?」
- 전자칠판에서는 한 단계씩 함께 읽고 학생이 고른 이유와 관찰 근거를 먼저 묻습니다. 서로 다른 답은 자료를 다시 비교하는 토론으로 잇습니다.
- 모둠 수업에서는 모둠이 태블릿 한 대로 활동을 돌려 가며 조작하고, 마지막에 기록탑에서 장소마다 액자를 눌러 함께 되돌아봅니다.
- 설정의 「교사용 전체 해금」으로 모든 활동·엔딩·인증서를 미리 볼 수 있습니다. 시연 중 답과 보상은 학생 기록에 저장되지 않습니다.

## 7. 저장과 다시 하기

- 진행은 이 기기의 브라우저에 이 앱 주소별로 저장됩니다. 다른 기기·브라우저로 이어지지 않고, 공용 기기에서는 다음 사용자가 기록을 볼 수 있습니다.
- 수업에서는 같은 주소(운영 주소)를 쓰세요. 테스트용 미리보기 주소의 기록은 운영 주소에 섞이지 않습니다.
- 처음부터 다시 하려면 설정 → 아래쪽 「탐험 기록 초기화」 → 「기록 지우기」를 누릅니다. 모은 도구, 활동 진행, 관찰 기록이 지워지고 되돌릴 수 없습니다. 소리 설정은 그대로 남습니다.
- 인증서는 별명을 쓴 뒤 「인증서 인쇄 / PDF 저장」으로 출력합니다. 별명은 저장하거나 전송하지 않습니다. 인증서에는 탐험을 마친 날짜(예: 2026. 11. 22.)와 제작 표기가 함께 나옵니다.
- 설정 창은 아래쪽 「닫기」 버튼이나 Esc 키로 닫습니다.

- 폰 가로에서 지도 위 장면 글자 일부가 20px보다 작습니다.

- 단원 번호와 예상 시간은 저장소에서 확인하지 못했습니다.
