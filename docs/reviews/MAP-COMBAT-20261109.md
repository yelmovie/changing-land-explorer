## 적용
- 지질 테마 상상 악당 ‘돌먼지 대장’: 생성한 3×2 시트, 대기/걷기2종/공격/피격/무너짐.
- 기존 리버의 모자·스카프·조끼·가방을 보존한 4포즈 시트: 준비/공격/피격/회복. 기존 8방향 걷기는 유지.

- 지도 끌기/전체 보기/방향키/WASD/터치 이동, 음소거, 움직임 줄이기, Phaser 없는 fallback 유지.
