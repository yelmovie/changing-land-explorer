## 3. 중복 조작 버튼 전수 점검

화면마다 보이는 조작 요소를 JS로 뽑아 확인했다(`report.json`의 `ctrls`).

| 화면 | 보이는 조작 | 중복 | 처리 |
|---|---|---|---|
| 홈 | 소리·설정·「리버와 탐험 시작」 | 없음 | 유지 |
| 지도 | 홈·뒤로·카드 보관함·소리·설정, 장소 이름표 5, 주민 5, 기록탑, 방향판(리버 걷기 4+가운데), 손으로 이동·전체 보기, 「○○ 가기」 | 이름표와 「○○ 가기」가 같은 장소로 감 | 유지: 3초 목표(다음 장소 안내 버튼)로 정한 결정이고, 다음 장소가 화면 밖일 때 유일한 안내 |
| 주민 대화 | 오른쪽 위 X + 「지도로 돌아가기」(둘 다 대화창 닫기), 다시 듣기, 질문 2, 도장 받기, 주민 목록 | **X = 「지도로 돌아가기」** | **X 숨김**(대화 화면만. 주민 목록 화면은 다른 닫기가 없어 X 유지). 처음 포커스는 대화 넘기기 버튼으로 |
| 활동 5곳 | 홈·뒤로·소리·설정, 장면, 「자동 재생」, (화산) 「재료 골라 놓기」·「분출물 골라 관찰」, 다 하면 「다음 발견」 | 화산의 「…골라 놓기」는 끌기와 같은 일 | 유지: 캔버스 물체는 키보드 초점을 못 받아서 이 버튼이 키보드·터치 대체 경로(`check-volcano-touch` 검사 대상). 「다음 발견」이 준비되면 다른 조작은 숨겨져 주 버튼은 늘 하나 |
| 대피 3D | 도구 메뉴, 방향판 4, 여진 때만 「몸 낮추기」 | 없음(3초 작업에서 정리됨) | 유지 |
| 현장 작전 | 현장 조작 버튼, 「자동 관찰」 또는 「관찰로」·「다시 도전」, 성공 뒤 「스테이지 완료」 | 없음 | 유지 |
| 보상 카드(작전 성공·탐구 완료) | X + 「마을로 돌아가기」 | **X = 닫기, 실제 진행은 「마을로 돌아가기」뿐** (X를 누르면 끝난 화면에 남음) | **X 숨김**, 포커스는 「마을로 돌아가기」 |
| 기록탑 | 액자 5, 「개념 영상 모아 보기」, 주 버튼 「기록탑 완성하기」 | 없음 | 유지 |
| 엔딩 | 액자 5, 「다시 지도로」·「개념 영상 모아 보기」·「마무리 영상 다시 보기」, 주 버튼 「나의 탐험 인증서」 | 하는 일이 모두 다름, 주 버튼 1개 | 유지 |
| 인증서 | 별명 입력, 「인증서 인쇄 / PDF 저장」, 「탐험 기록으로」 | 없음 | 유지 |
| 개념 영상 창 | X + 「다음 활동으로」 | X와 「다음 활동으로」가 겹침 | 보고만: `src/concepts.js`·`concept-focus.css`는 개념 영상 자막 세션이 수정 중 |

없앤 중복: 2개(주민 대화 X, 보상 카드 X). 로직·판정·저장은 그대로이며, Esc로 닫기도 그대로 된다.
