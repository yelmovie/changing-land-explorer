# 땅의 변화: 야간 증분 검토 · 2026-11-08

## 실제 변경
- 새 생성 그림 **0개**. 기존 `art/volcano-ash-puff-1-v1.webp`, `art/volcano-ash-puff-2-v1.webp` 2개를 재사용했다. 이 자산의 원래 생성 도구/모델을 새로 주장하지 않는다.
- `src/observation-scenes.js`: 저장된 도시 관찰 기록/비교 그림의 회색 타원 화산재를 기존 투명 화산재 그림으로 개선했다. 분출 전후 상태와 같은 배경/카메라를 유지한다.
- `src/adventure/city.js`: 실시간 장면은 이미 생성 화산재를 사용하므로 공유 레이어의 동일 화산재가 중복되지 않도록 제외했다.
- `scripts/overnight-art.test.mjs`: 기록 그림, 프리로드 목록, 실제 파일의 일치와 안전 확인 뒤 화산재가 사라지는 상태를 검사한다.

## 5단계 시각 검토
- 강: 모래 실험 이미지 위 물줄기/퇴적 상태는 실제 조작 데이터로 유지.
- 화산: 생성 산·쟁반·주사기와 붉은 물 모형 유지. 모형의 붉은 물은 용암이 아니라는 설명 유지.
- 암석: 이미 교체된 현무암/화강암 표본과 붓, 관찰 도구 유지.
- 도시: 기존 실시간 생성 화산재를 저장 관찰 자료에도 일관되게 활용.
- 안전: 최근 생성된 책상·교실·대피 환경과 선택·안전 판단 보존.

## 과학·후속
- [4과11] 현무암/화강암 관찰, 실제 화산과 모형 차이, 지진 안전 중심을 유지했다. 지진 원인이나 분출 직후 즉시 비옥해진다는 내용을 추가하지 않았다.
