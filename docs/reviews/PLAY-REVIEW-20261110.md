## 점검 범위

- 기준 확인: `dist` 270개 파일을 https://geovalley.pages.dev/ 와 SHA-256으로 대조해 269개 일치. 다른 1개는 빌드 시각이 들어가는 `sw.js` 캐시 이름뿐이다.
- 실제 플레이(빌드본, 로컬 5207, Playwright + 헤드리스 Chrome): 시작 → 인트로 → 지도 → 다섯 장소의 입장 창 → 10개 활동 30단계 → 개념영상 10편(끝까지 재생, 자막 3개씩 확인) → 보상 창 5개 → 주민 대화·도장 5명 → 축제 광장 → 기록탑 3라운드 → 엔딩 영상 → 탐험 기록 → 인증서까지 학생 모드로 진행했다. 지도에서는 장소 이름표를 눌러 걸어갔고, 활동은 실제 끌기·탭·슬라이더·키보드로 조작했다.
- 오답 경로: 이름표를 다른 원에 놓기, '언덕 위쪽' 고르기, 관찰 카드를 반대쪽에 놓기, 화산 재료 순서 틀리기, 엉뚱한 곳에서 흐른 길 그리기, 비교 카드 잘못 놓기, 틀린 색·알갱이 카드, 주문과 다른 표본 보내기, 다른 이름 상자에 넣기, 기록을 다른 시기에 붙이기, 안내판 칸 틀리기, 책상 아래로 가기 전 머리 보호, 흔들림이 멈추기 전 확인, 깨진 유리 쪽으로 걷기, 기록탑에서 기록 없이 시작·높은 곳 고르기·현무암 고르기·건물 가로지르는 길.

## 남은 문제와 이유

1. 끌어서 놓다 실패해도 소리가 없다. 여러 활동(암석 특징 카드, 이름 상자, 먼지 털기)이 성공 때도 놓기 함수에서 `false`를 돌려주는 구조라, 실패음을 일괄로 넣으면 정답에도 실패음이 난다. 활동별로 손봐야 해서 이번에는 두었다.
2. 시간 관측소 '분출 당시' 농장 그림은 화산재가 밭을 덮은 모습이 약하고, 화산재 실내 장면의 창밖이 맑다. 그림 교체가 필요하다.
3. 암석 분류에서 맞는 상자를 골라도 표본이 상자에 들어가지 않고, 나타난 두 상자가 확대 그림 아래쪽('2.4배 확대')을 가린다.
4. 화산 비교판 줄 이름 '함께 나오는 / 것'이 한 글자만 다음 줄로 넘어간다. 폰 가로에서는 캔버스 안 글자가 10~11px로 작다(같은 내용을 DOM 버튼으로 고를 수 있다).
5. 화성암의 생성 조건(땅속에서 천천히·땅 위에서 빨리 식음)과 알갱이 크기의 관계는 다루지 않는다. 오개념은 아니지만 교과서 범위에 넣을지 교사 판단이 필요하다.
6. 인트로·엔딩 영상의 리버 목소리와 자막이 일치하는지는 귀로 확인하지 못했다(자막 문장만 확인).
7. 리버 대사 음성: 계획(27줄)을 `voice/07/plan.json`에 썼다. 파일이 오면 적용한다.
8. `npm run check:requested`는 기준 커밋에서도 같은 곳("flag returned to its original place")에서 실패한다. 지금은 없는 강 활동의 예측 깃발을 기준으로 한 옛 검사다.
