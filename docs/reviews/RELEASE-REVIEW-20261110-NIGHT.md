## 판정: 조건부 배포 가능

학습·저장 핵심 경로는 통과했다. 실제 기기·학급 검수와 기존 자산의 권리 확인 조건은 남는다. 작은 화면의 일부 캔버스 글자와 전체 키보드 동등 경로까지 완성됐다고 주장하지 않는다.

## 변경 기준과 충돌 방지

## 발견과 수정

1. **830×515 개념창 잘림**: 최신 기준본에서도 10개 개념창에 불필요한 스크롤/하단 버튼 이탈. 낮은 가로 레이아웃의 적용 높이를 480→600px로 넓혔다. 기존 480px landscape 예외는 보존했다. 본문20px·버튼48px와 기존 글꼴을 유지했다.
2. **지도 공격 안내 가독성**: 12~14px였던 안내 본문을20px, 보조글을14~16px로 만들고 “다가가서 3번 공격!”으로 짧게 정리했다. 다시도전 설명도20px로 맞췄다. 공격 조건·거리·3회타격·저장·학습 관문은 그대로다.
3. **부분 복구 원본 보존**: 저장 데이터를 정리해 읽을 때 값이 바뀌거나 삭제되면 원문 문자열을 별도 키에 보존한 후 자동저장한다. 기본값을 덧붙이는 정상 이관에는 불필요한 백업을 만들지 않는다. 용량 부족/다른 기존 원본이 있으면 덮어쓰지 않고 현재 활동을 읽기 전용으로 전환한다. 명시적 기록 초기화에서만 사본도 제거한다.
4. **QA 품질**: 개념창 캡처 전 포스터 decode를 기다려 빈 화면을 결과로 남기지 않는다. 복구 검사 스크립트는 PLAYWRIGHT_PATH로 실행 가능하다.

## 디자인·게임 설계 판단

일러스트 마을·리버·도구 시각 언어를 유지했다. 접이식 화면에서는 영상과 핵심 설명을 나란히 두고 필수 조작을 한 화면에 남겼다. 공격 안내만 읽기 쉬워지고 그림을 덮지 않도록 문장을 줄였다. 새 장식 그림이나 불필요한 상시 애니메이션은 추가하지 않았다.

침식/운반/퇴적 관찰→화산 모형과 실제 비교→암석 분류→시간에 따른 영향→안전 경로 전이의 학습 흐름을 확인했다. 지도 전투를 해도 학습 증거를 대신 얻지 못하고 관찰 활동의 보상 조건을 건너뛰지 않는다. 오답 후 재관찰과 재시도가 가능하다. 최종 힌트가 답에 가까운 구간, 캔버스의 작은 보조 글자·키보드 동등 경로는 다음 개선 대상이다.
