# 개념 영상 설명 화면 개선 · 2026-11-09

## 변경 범위

기존 개념 영상 10개의 설명 모달만 개선했다. 과학 설명 문구, 동영상·포스터, 활동 완료 조건, 교사 해금, 학생 기록 저장 방식은 유지했다.

- 현재 장면의 과학 개념을 큰 제목과 `1 / 3` 표시로 분리했다.
- 자막과 `기억해 두기` 요약에 서로 다른 서체 역할·간격을 적용했다.
- 기존 도해를 넓게 보여 주고, 동영상 시간에 맞춘 진행 표시를 추가했다.
- 장면 선택은 해당 시점에서 멈추며 재생·일시정지는 별도 버튼이다.
- 영상 자체를 눌러 재개할 때 처음부터 다시 시작하지 않도록 고쳤다. `다시 보기`만 처음부터 재생한다.
- 자막은 장면이 바뀔 때만 갱신해 스크린리더의 중복 알림을 줄였다.
- 영상 실패 시 모든 핵심 자막을 보존하고 `핵심 내용` 제목을 유지한다. 늦은 미디어 이벤트가 오류 상태를 덮어쓰지 않는다.
- 터치 버튼은 최소 48px. 작은 세로 화면에서는 쌓기 배치, 높이가 낮으면 모달 내부 스크롤을 사용한다.
- 짧은 자막 전환과 버튼 반응만 사용하며, 감소 모션에서는 자동재생과 전환을 억제한다.

## 설치된 디자인 스킬 적용

- Impeccable: 실제 `context --target src/concepts.js` 실행. 기존 제품·디자인을 근거로 한 제한적 개선 경로를 따랐다. Read 모드 타이포, polish, craft-floor 기준을 적용했다. 최종 detector 결과는 `[]`다.
- Hallmark: 기존 콘텐츠·동작·브랜드 보존, 색상·서체 토큰화, 포커스·감소 모션·뷰포트 확인에 적용했다. 실제 개념 모달을 띄우는 로컬 미리보기에서 `sloplint --scope app --genre playful --render` 실행: 필수 FAIL 0건.
- Taste: 기존 UI에 맞는 동일한 정렬선, 짧은 hover/press, 하나의 정보 위계, 실제 미디어 중심 구성을 적용했다. 마케팅 페이지용 hero·사진·회사 소개 구성은 교육용 모달에 도입하지 않았다. Taste 전체 게이트 통과를 주장하지 않는다.
- Hallmark 권고 36건은 명시적으로 유지: 33건의 4px 격자 외 간격은 기존 학습 화면·한글 조판 및 낮은 화면에 맞춘 값, 2건의 흰색은 녹색 재생 버튼과 선택 번호의 대비, 1건의 버튼 높이는 초등 태블릿의 56px 목표를 유지하기 위함이다. 해당 화면의 필수 실패가 아니다.
