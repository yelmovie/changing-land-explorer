# 지도 캐릭터·주민·교사용 해금 점검 — 2026-11-03

## 변경

- `src/river-walk.js`, `src/map-adventure.js`: 앞·뒤·좌우·대각선 8방향, 방향별 4프레임의 새 리버 스프라이트 적용. 이동 거리에 맞춰 프레임을 바꾸며 발 위치와 그림자를 맞춘다. 정지·대화·숨김 탭에서는 걷기를 멈춘다. 움직임 줄이기와 이미지/Phaser 로드 실패 대체 동작을 유지한다.
- `src/main.js`, `src/map-adventure.js`: 처음 장소를 완료하면 보상 버튼에서 해당 주민 이름을 안내하고, 지도의 주민 버튼으로 바로 대화할 수 있다. 대화한 뒤에는 주민 목록으로 돌아간다. 화면 문구와 접근성 이름을 함께 바꾼다.
- `src/ui.js`, `src/adventure/index.js`: 교사 시연에서 열린 자물쇠 아이콘과 상태 이름을 표시한다. 학생의 완료 체크와 아직 잠긴 단계를 구분한다.
- 실행 이미지 `public/assets/characters/river-walk.webp`: 512×1280, 투명 배경, 32프레임, 234,824 bytes. 지도에 진입할 때 로드한다.
- 원본과 생성 프롬프트는 [제작 기록](../design/river-walk-prompts.md), 이전 파일 이동은 [폴더 안내](../FOLDER-GUIDE.md)에 기록했다.

## 실제 검사

Windows x64 · Node 24.14.0 · Chrome/Playwright에서 확인했다.

- `npm run check`: 통과.
- `npm test`: 45/45 통과.
- `npm run build` 및 생성한 service worker 문법 검사: 통과.
- 실제 지도 길 이동 8방향: 올바른 방향 행과 걷기 프레임 전환, 도착 후 정지 프레임 확인.
- CPU 4배 지연에서 설정 창 정지·재개, 도착하기, 지도 화면 종료 시 Phaser destroy 확인.
- 움직임 줄이기, 시트 로드 실패, Phaser 로드 실패의 대체 동작 확인.
- 실제 첫 미션의 마지막 관찰 → 개념 영상 → 복구 보상 → 나루 만나러 가기 → 새 주민 버튼 → 대화 → 닫기 → 주민 목록 전환 확인.
- 완료한 장소 0~5개에 따른 NPC 수·건물 불빛·완료 및 잠금 아이콘 확인.
- 교사 시연의 10개 활동, 각 활동 단계 이동, 마지막 도전·엔딩·인증서 메뉴를 확인했다. 시연 종료와 새로고침 뒤 학생 저장 원문이 같았다.
- 지도/주민 화면은 1280×720, 768×1024, 850×420, 휴대폰 세로에서 가로로 회전한 상태를 확인했다.
