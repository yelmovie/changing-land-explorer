2026-11-05 · macOS · Chrome 156 / Playwright · Node 24.22.2 · Cloudflare Pages 대상. 기준 체크아웃 `2e8463b`, 이전 운영 배포 기록 `b64d14a` ([인계 문서](../../HANDOFF.md)). 착수 시 `HANDOFF.md`, `scripts/build.mjs`에 있던 수정은 보존했다. `edu-design`으로 수정하고 `game-final-check`와 `edu-final-check`로 검증했다.

- `npm run check`, `npm test` 73개, `npm run build` 통과. exFAT의 `._*`는 문법 검사·Git·배포 빌드에서 제외한다.
