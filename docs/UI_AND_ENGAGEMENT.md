# 공통 UI 요구사항과 몰입 고도화 제안

작성: 2026-10-12. 공통 아이콘·전체 해금은 사용자 요청으로 확정. 상세 동작은 아래의 구현 기준으로 제안한다. 재미·3D 항목은 검토안이며 채택 확정이나 구현 완료를 의미하지 않는다.

## 1. 모든 페이지의 공통 아이콘

메인, 스테이지 선택 맵, 활동 01~10, 최종 복구, 엔딩, 인증서 화면에 같은 위치로 제공한다. 인증서 출력물에는 게임 조작 UI를 제외한다.

| 위치 | 순서 | 기능 |
|---|---|---|
| 좌측 상단 | 홈, 이전 페이지 | 메인으로 이동, 게임 내부의 이전 화면으로 이동 |
| 우측 상단 | 소리, 톱니바퀴 설정 | 전체 소리 켜기/끄기, 설정창 열기 |

- 아이콘은 공통 SVG 컴포넌트로 사용하며 배경에 구워 넣지 않는다.
- 권장 터치 영역 56×56 CSS px, 최소 48×48 CSS px. 대비가 확보된 배경판을 두고 제목·게임 조작 영역과 겹치지 않게 한다.
- 각 아이콘에 접근 가능한 이름, 포커스 표시, 누름 상태를 제공한다. 소리는 켜짐/꺼짐을 모양과 상태값으로 함께 표시한다.
- 메인에서는 홈과 이전 아이콘의 위치를 유지하되 비활성으로 표시한다. 처음 시작하여 이전 화면이 없는 경우에도 이전은 비활성이다.
- 이전은 브라우저 방문 기록이 아닌 게임 내부 이동 기록을 사용한다. 활동 B에서 A로 돌아가고, 맵에서 입장한 활동 A는 맵으로 돌아간다. 설정 열기/닫기는 페이지 이동 기록에 넣지 않는다.
- 홈·이전으로 이동할 때 진행, 관찰 기록, 실험 조건을 보존한다. 완료 처리나 리셋을 자동으로 하지 않는다.
- 맵 복귀 시 입장 전 위치를 복원하되 입구 재진입으로 즉시 활동이 열리지 않도록 한다.

## 2. 섹션을 나누지 않는 단일 설정창

톱니바퀴를 누르면 한 개의 설정창 안에 아래 항목을 모두 표시한다. 탭, 아코디언, 별도 관리자 하위 화면을 만들지 않는다.

1. 전체 소리 켜기/끄기
2. 관리자 전체 해금 켜기/끄기
3. 닫기

소리 아이콘과 설정의 소리 스위치는 같은 상태를 공유한다. 배경음·효과음·음성 안내를 함께 켜거나 끄고, 페이지 이동 후에도 유지한다. 브라우저의 오디오 재생 제한에 따라 최초 사용자 입력 전에는 재생을 강제하지 않는다.

**관리자 전체 해금**

- 스위치 한 번으로 5개 스테이지, 활동 10장, 최종 복구·엔딩·인증서까지 모든 페이지의 진입 제한을 함께 해제한다.
- 스테이지별 해금 버튼이나 구역별 설정은 제공하지 않는다.
- 해금 중인 맵에서는 각 미션의 A/B 활동과 최종 화면으로 바로 진입할 수 있는 이동 수단을 제공한다. 잠금만 풀고 실제 접근 경로가 없는 상태를 만들지 않는다.
- 해금은 진입 권한만 바꾼다. 실제 완료 여부, 조사 기록 획득, 학생 진행률은 자동으로 채우지 않는다.
- 선행 관찰 기록이 없는 활동이나 최종 화면을 시연할 때는 별도 임시 예시 데이터를 제공하고 관리자 미리보기임을 표시한다. 학생 저장 데이터와 섞지 않는다.
- 미완료 상태에서 연 인증서는 예시 미리보기로 표시한다. 실제 학습 완료 인증서로 오인시키지 않는다.
- 해금을 끄면 기존 학생 진행에 따른 잠금으로 복귀한다. 진행 데이터는 삭제하지 않는다.
- 제안 기본값은 꺼짐이며 관리자 해금 상태는 현재 실행 동안만 유지한다. 소리 설정은 기기에 저장한다.
- 비밀번호·로그인·별도 권한 체계는 요청되지 않았으므로 추가하지 않는다. 이 기능은 로컬 교사 시연 편의 기능이다.

설정이 열려 있는 동안 배경의 캐릭터 이동·실험 재생·게임 입력을 멈추고 닫으면 이전 상태로 돌아간다. 배경은 클릭되지 않으며 키보드 포커스도 설정 안에 머문다.

## 3. 재미·몰입을 위한 제안

| 대상 | 구체적인 플레이 변화 | 의미 있는 결과 |
|---|---|---|
| 선택 맵 | 장소에 가까워지면 NPC가 짧은 의뢰를 하고 입구가 반응한다. 안내는 처음 한 번, 이후 건너뛰기 가능 | 어디를 왜 조사하는지 알면서 이동한다. 재방문에는 빠른 이동도 제공해 이동 반복을 줄인다 |
| 미션 1 | 처음 놓은 예상핀과 실험 결과를 겹쳐 보고, 조건 하나를 바꿔 두 실험을 비교한다 | 예측이 빗나가도 감점 대신 다시 실험할 이유가 생긴다 |
| 미션 2 | 분출을 멈춘 장면에서 관찰 지점을 표시하고 실제 화산의 대응 장면과 연결한다 | 재생 버튼을 누르는 것에서 끝나지 않고 직접 잡은 장면이 비교 근거가 된다 |
| 미션 3 | 이름을 숨긴 표본을 관찰한 뒤 감정한다. 후속 확장에서는 외형이 다른 표본에 같은 관찰 기준을 적용한다 | 표본 그림을 외우기보다 자신이 찾은 특징으로 판단한다 |
| 미션 4 | 학생이 고른 자료로 주민 안내판이 완성되고, NPC가 정보의 활용을 짧게 보여준다 | 보고서 제출이 도시 정보망의 변화로 이어진다. 정답 선택이 자연재해를 막는 것처럼 연출하지 않는다 |
| 미션 5 | 그린 경로를 캐릭터가 실제 따라간다. 위험한 지점에서 멈추면 해당 구간만 고쳐 다시 시도한다 | 판단한 경로의 결과를 즉시 확인한다. 제한시간·감점으로 안전 판단을 서두르게 하지 않는다 |
| 공통 보상 | 학생이 표시한 사진·증거핀이 조사 가방에 남고, 맵의 관측선·연구소 불빛 등이 복구된다 | 학습 행동과 보상이 직접 연결된다 |
| 엔딩 | 공용 완료 장면에 더해 학생이 실제 남긴 관찰 기록과 대피 경로를 다시 보여준다 | 내가 수행한 조사라는 감각을 남긴다 |

우선순위: 학생 조작에 따른 현상 변화 → 개인 관찰 기록의 다음 활동 연결 → 지역 복구 반응 → 짧은 NPC·음향 연출. 추가 표본, 보너스 조사, 장식 수집은 핵심 흐름 완성 뒤 검토한다.

## 4. 3D를 넣을 만한 화면 — 미확정 제안

현재 확정 기준은 선택 맵만 2.5D 픽셀아트 RPG, 장소 내부는 2D다. 아래는 사용자가 요청한 가능성 검토이며, 기존 2D 기준을 자동으로 변경하지 않는다.

| 화면 | 제안 | 학습상 목적 | 우선순위·조건 |
|---|---|---|---|
| 05 암석 관찰실 | 2D 연구실 중앙의 암석 오브젝트만 3D로 회전·확대. 관찰핀은 표본 표면을 따라 유지 | 여러 면의 색·알갱이·표면을 직접 비교 | 가장 우선. 과학적으로 검수된 표본·텍스처가 필요하며, 인공적인 무늬가 관찰 판단을 왜곡하면 사용하지 않는다 |
| 03 화산 모형 구성실 | 2D UI 안에 제한 회전 가능한 화산 오브젝트, 단면 보기 추가 | 겉모습과 내부 위치 관계를 비교 | 선택 도입. 2D 단면으로 목적을 충분히 달성하면 3D를 생략한다. 모형 실험과 실제 화산 단면을 명확히 구분한다 |
| 01 흐르는 물 실험실 | 지형을 약간 돌려 깎인 곳·쌓인 곳의 높이 차이를 관찰 | 지형 변화의 공간적 차이 확인 | 후속 검토. 물·흙·지형 변화와 시간 되감기가 함께 맞아야 하므로 MVP 우선순위는 낮다 |
| 02·04·06~10 및 최종 화면 | 2D 유지 | 비교·증거 연결·시간 변화·행동 판단에 집중 | 화면 전체의 3D 전환을 제안하지 않는다 |

추천 조합은 **선택 맵 2.5D + 활동 화면 2D + 05장 암석만 부분 3D**. 03장 화산은 필요할 때 추가한다. 3D 채택 시 해당 화면 진입 때만 자원을 불러오고, 지원하지 않는 기기에는 검수된 여러 방향의 2D 표본 이미지를 제공하는 방향을 검토한다.

## 5. 구현 후 확인할 항목

- 모든 게임 페이지에서 네 아이콘의 위치·누름 영역·상태가 일관적인가?
- 홈·이전 이동 후 관찰 기록이 유지되고 맵에서 입구 재진입이 반복되지 않는가?
- 소리 아이콘과 설정 상태가 동기화되고 음소거가 모든 게임 소리에 적용되는가?
- 설정은 한 번에 열리고 배경 입력·재생이 멈추는가?
- 전체 해금 한 번으로 모든 화면에 접근할 수 있고, 학생 완료 기록은 바뀌지 않는가?
- 선행 기록이 없는 직접 진입, 해금 해제, 미완료 인증서 미리보기가 정상 동작하는가?
- 관리자 시연을 종료한 뒤 학생 데이터에 예시 기록이 남지 않는가?

현재는 문서 반영만 완료했다. 실행 가능한 앱 소스가 없어 렌더링·터치·이동·저장·오디오 검증은 아직 수행하지 않았다.
