공항·온천은 **복구 · 안전 확인 뒤**, 농장은 **아주 오랜 시간 뒤**를 수첩의 읽을 수 있는 본문에도 표시한다. 붉은 물과 실제 용암, 화산재와 기체, 암석의 색·알갱이 두 근거, 분출 당시 피해와 이후 이용의 차이를 유지했다.

학교 안전 순서는 머리·몸 보호 → 다리 잡고 기다리기 → 흔들림 멈춤 확인 → 교사 안내에 따른 이동이다. [기상청에 실린 학교 지진 행동요령](https://www.weather.go.kr/pews/man/m_n.html)의 학교 항목과 대조했다. 활동에는 가상 행동 연습이며 실제 대피 훈련은 선생님과 함께한다는 문구가 있다.
