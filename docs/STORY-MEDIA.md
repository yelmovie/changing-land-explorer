# 지오밸리 이야기 영상과 테마 음악

첫 탐험은 리버의 수첩에서 흐려진 기록과 강가의 모래를 보여 준 뒤, 학생에게 물길을 조사하자고 제안한다. 마지막 기록탑 문제를 마치면 학생이 찾아낸 증거를 되짚고, 불이 돌아온 기록탑과 인증서를 보여 준다. 영상이 끝나거나 건너뛰면 인트로는 지도, 엔딩은 실제 탐험 기록으로 이어진다.

| 쓰는 곳 | 보관한 원본 | 앱에서 읽는 파일 |
|---|---|---|
| 처음 시작 · 설정에서 인트로 다시 보기 | `assets/source-media/video/intro.mp4` | `public/assets/story/intro.mp4` |
| 기록탑 완료 · 설정 또는 교사 시연에서 엔딩 다시 보기 | `assets/source-media/video/final.mp4` | `public/assets/story/final.mp4` |
| 인트로 · 지도 · 탐구 활동 | `assets/source-media/audio/main-theme.mp3` | `public/assets/audio/main-theme.mp3` |
| 엔딩 · 탐험 기록 · 인증서 | `assets/source-media/audio/final-theme.mp3` | `public/assets/audio/final-theme.mp3` |

웹용 영상은 H.264/AAC 1280×720 MP4이며, 첫 화면 이미지는 같은 디렉터리의 WebP다. 원본 파일은 그대로 두었다. 게임은 외부 스트리밍이나 운영체제별 경로를 쓰지 않는다.

**수정 위치.** 두 편의 자막은 [src/story.js](../src/story.js) 상단에 재생 초 단위로 모았다. 아래 다섯 장면에서 한 문장씩 보여 준다. 자막·일시 정지·구간 이동·건너뛰기는 영상 화면에서 조작한다.

| 인트로 (약 17초) | 엔딩 (약 17초) |
|---|---|
| 0.35초 · 금이 간 기록탑 | 0.38초 · 물이 흙을 깎고 옮긴 흔적 |
| 2.13초 · 리버의 흐려진 수첩 | 3.77초 · 색과 알갱이로 구별한 돌 |
| 5.82초 · 강가의 모래는 어디서 왔을까? | 7.60초 · 안전한 대피 길 |
| 9.24초 · 물을 흘려 단서 찾기 | 11.75초 · 다시 불이 켜진 기록탑 |
| 12.18초 · 다리를 건너 물길로 | 14.16초 · 탐험가의 인증서 |

**음악.** [src/music.js](../src/music.js)에서 한 번에 한 테마만 재생한다. 영상의 일시 정지·탐색에 맞춰 같은 위치로 이동하고, 영상이 끝나면 해당 곡의 다음 부분이 이어진다. 메인 테마만 반복한다. 기본 음악 크기는 30%이고 설정에서 바꿀 수 있다. 전체 소리 스위치는 영상 원음·음악·효과음에 함께 적용된다. 개념 영상이 열리거나 탭이 숨겨지면 음악을 멈춘다.

**참고한 구성.** [공유 제작 현황](https://docs.google.com/spreadsheets/d/1Ok9VRUKXi6XNlHPXbELsMduD3ZHamQtDbsPbLDTk1Bs/edit?gid=987902134#gid=987902134)에 있는 [식물의 생활](https://leafy-garden.pages.dev/)과 [생물의 한살이](https://life-clock-lab.pages.dev/)의 도입·엔딩 재생, 자막과 테마 전환 방식을 참고했다.

**다른 컴퓨터에서 확인.** Node.js 20 이상에서 `npm run dev`로 열면 된다. 다시 인코딩할 필요는 없다. 시작한 기록에서는 **설정 → 인트로 영상 다시 보기**, 완주 전 엔딩은 **설정 → 교사용 전체 해금 → 시연 메뉴 → 엔딩**으로 확인한다. 교사 시연은 학생의 완료 여부를 바꾸지 않는다.
