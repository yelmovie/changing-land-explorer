# 7 earthchange · 실제 적용 개선 프롬프트

## 요청과 보호 범위

6~16 프로젝트를 순서대로 고도화하되 1~5 완성작은 참고만 한다. 대상은 `7 earthchange` 하나다. 기존 미커밋 작업, 이미지·음성 원본, 기존 학생 기록을 보존한다. 커밋·푸시·공개 배포·새 패키지 설치는 하지 않는다. 자석 프로젝트는 수정하지 않는다.

## 이 프로젝트에 적용할 프롬프트

> 기존 따뜻한 지오밸리 아트와 다섯 장소의 고유 조작을 유지하라. 현재 구현과 자산부터 읽고, 필요 없는 이미지나 주민 목소리를 중복 생성하지 말라. 물길은 조건 비교와 흔적, 화산은 모형의 한계와 분출물, 암석은 두 관찰 근거와 주문 적용, 도시는 시간에 따른 변화와 생활, 안전은 몸 보호와 대피 경로라는 차이를 유지하라. 삭제된 예상 깃발 같은 과거 기능을 임의로 복구하지 말라.
>
> 90개 힌트에서 관찰 방향 질문, 조작 안내, 직접 정답 제공을 구분하고 실제 본 도움만 기록하라. 일반 힌트만 연 학생을 정답 힌트 사용자로 표시하지 말라. 직접 답을 본 기존 기록은 임의로 독립 수행 기록으로 바꾸지 말라. 기록은 재접속 후에도 유지하고 보상과 학습 평가를 분리하라.
>
> 다섯 장소·열 활동의 성취기준, 목표, 조작, 확인할 증거, 적용 상황, 모형의 한계를 구조화하라. 교사용 가이드에서 볼 수 있게 하고 목표와 근거가 빈 항목이 없는지 검사하라. 완료·보상을 독립적인 성취 증명이라고 말하지 말라. 암석 최종 과제의 회전 표본을 완전히 새로운 표본 전이라고 과장하지 말라.
>
> 기존 모모 주민 음성 25개를 재사용하라. BGM, 효과음, 주민 음성을 각각 조절하고 0 및 전체 음소거가 현재·예약된 소리에도 적용되게 하라. 음성 중 BGM은 잠시 멈추고 정상 종료·실패·교체·화면 이동·탭 숨김 때 보류를 정확히 해제하라. 다시 켰다고 종료한 음성을 자동 재생하지 말라. 전체 음소거/음악 설정과 다른 연출의 음악 보류를 보존하라.
>
> 1024×768, 1280×800, 915×412에서 독립 브라우저로 화면을 검사하고, 학생 새 기록에서 30개 발견→10개념→5보상→3적용→엔딩·인증서→재접속을 실제 포인터로 완주하라. DOM 검사 통과를 모든 캔버스 터치 표적 통과로 확대하지 말라. 소스와 최종 dist의 실행을 구분하고 실제 기기, 키보드 전체 경로, 수업 효과, 저작권, 공개 배포의 미검증은 남겨라. 고정 감점표로 전후 점수를 내라.

## 후속 실제 적용 프롬프트

작은 휴대폰에서 필수 캔버스 드래그의 접촉 면적이 부족한 부분을 찾아 48px/20px DOM 대체를 추가한다. 기존 판정 함수를 공유하고 학생이 관찰 위치·특징·카드·목적지를 직접 선택하게 한다. 정답이나 완료를 자동으로 넣지 않는다. 오답 거부와 선행 관찰 조건, 흔들림 대기 시간을 보존한다. 915×412와667×375를 포함해 실제 터치·가림·진행 검사를 하고, 전체 키보드와 실기 미검증을 별도로 유지한다.
