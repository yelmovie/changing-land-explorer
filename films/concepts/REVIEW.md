# 지오밸리 개념영상 10편 · 검토 기록 (2026-11-09)

## 무엇을 만들었나

- 앱 개념 영상 10편(`public/assets/concepts/{river,volcano,rocks,city,safety}-{0,1}`)을 HyperFrames 0.9.26으로 다시 만들었다. 이전 영상은 글자 없는 8초 SVG 도해였다.
- 한 프로젝트(`films/concepts/`)에 공용 부품(`kit.js`)과 편별 데이터(`scenes.js`)를 두고, 루트 변수 `film`으로 편을 골라 렌더한다. 편 수가 많아 부품 + 데이터 방식으로 묶었다.
- 흐름(6번 프로젝트 A안 "실험 노트"를 지오밸리 색·캐릭터로 번역): 공책 바탕 → **질문** 한 줄 → 방금 한 실험을 게임 그림으로 재현 → **확대 + 이름표**(이름표는 그 물체 위, 물체가 나올 때) → **정리** 한 줄 → **리버 반응**(장소에 맞는 포즈).
- 길이 8초 → **15초**. 앱 캡션 세 개를 5초씩(0·5·10초) 보여 주도록 맞췄다. 이전에는 2.7초마다 캡션이 바뀌어 4학년이 읽기 전에 넘어갔다.
- 그림은 전부 게임에 이미 있는 것: 모래 언덕 모형(마른/젖은), 퇴적 부채꼴, 물뿌리개, 강 풍경, 화산 모형·쟁반·주사기, 실제 화산 그림, 현무암·화강암 표본, 새 표본 C, 도시 분출/평온 그림, 화산재 덩어리, 교실·학교 지도, 리버 포즈 7종. 새로 생성한 이미지 0. 물줄기·붉은 물·경로·이름표·확대경·책상·위험 표시만 코드로 그렸다.
- 마지막 프레임(14.9초)이 포스터다. 움직임 줄이기 사용자는 자동재생 없이 이 장면(질문·세 이름표·정리·리버)과 DOM 캡션을 본다.

## 결정과 이유

- **소리 없음.** 앱이 영상을 `muted`로 자동재생하고(브라우저 자동재생 정책) 효과음은 앱의 소리 체계(`playSound('observe')`, 음소거 설정)가 맡는다. 영상에 효과음을 넣어도 앱에서는 들리지 않으므로 무음으로 렌더했다. `check`의 `audio_none`(info)은 의도한 것.
- **아래 칩 줄 숨김.** 이름표가 영상 안 물체 위에 있으므로 영상 아래에 같은 낱말을 다시 띄우던 `.concept-labels`는 `display:none`. 같은 낱말은 장면 버튼(DOM)에 그대로 있다.
- **확대와 이름표.** 카메라가 움직이면 그 전에 보이던 이름표는 잠깐 물러났다가 전체 그림으로 돌아올 때 제자리에 다시 붙는다(본 것은 종이색, 새것은 금색). 프레임마다 시간만으로 결정되도록 이름표를 두 벌(확대용·전체용) 정적으로 두었다(되감기 콜백 없음).
- **흔들림(안전 1).** 6px·4px 작은 좌우 흔들림만, 12초 전에 멈춘다. 감각 예민 학생을 고려해 화면 전체 번쩍임·큰 진동은 넣지 않았다.
- **과학 내용.** 모형의 붉은 물은 "흐름만 나타냈어"로 정리(용암 아님). 도시 1은 "아주 오랜 시간 뒤"를 명시해 분출 직후 비옥해진다는 오개념을 피했다. 암석 이름표 문구는 게임의 `FEATURES` 낱말(전체가 어두운색/알갱이가 잘 안 보임 등)을 그대로 썼다. 입자 모형 없음.
- 금지 목록 확인: 어두운 바탕 네온·빛번짐·떠다니는 입자 장식 없음, 보라/파랑 그라데이션 없음, 글래스 카드 없음, 01/02 번호 없음, 카드 세 장 나란히 없음, 전부 동시 페이드업 없음(질문은 낱말별, 이름표는 점→선→라벨 순, 정리는 낱말별 색 전환), 읽는 동안 글자 움직임 없음(착지 후 정지).

## 측정한 것 / 눈으로만 본 것

- `snapshot`: 10편 모두 2.5·7·14.9초(일부 1.5·3.5·6.8·10초 추가) 프레임을 직접 열어 봤다. 고친 것: 확대 화면이 질문 줄을 덮음 → 무대 `clip-path`로 질문 아래만 보이게; 확대 중 앞 이름표가 엉뚱한 곳을 가리킴 → 물러났다 돌아오게; 암석 2의 이름표가 정리 줄에 가림·표본이 이름판을 덮음 → 위치 조정; 도시 1의 두 이름표 겹침; 안전 1에서 리버 손과 책상 다리가 어긋남 → 리버를 오른쪽 다리 옆으로.

## 가장 약한 장면과 다음에 할 일

- **도시 1(관찰→행동)**: 화산재 덩어리 그림이 확대 화면에서 크고 무겁게 보인다. 시간이 있으면 화산재를 얇은 회색 층(땅에 쌓인 재)으로 바꾸겠다.
- **강 2**: 상류→하류 이동 알갱이가 확대 전후로 작아 잘 안 보인다. 알갱이 크기를 키우거나 물길 폭 화살표를 더하면 좋다.
- 리버 반응은 등장 + 한 번 끄덕임뿐이다. 걷기 스프라이트(`characters/river-walk.webp`)로 안전 2의 이동을 걷는 동작으로 바꾸면 더 살아난다.
- 다시 렌더: `PLAYWRIGHT_PATH=<playwright/index.mjs> TMPDIR=<외장 경로> node films/concepts/render.mjs [편 이름…]`. 한 편 확인: `sh films/concepts/snap.sh <편> 2.5,7,14.9 <출력 폴더>`.

강 2의 일반화에 ‘대체로’를 추가했다. 화산 2의 기체 표지를 발생 위치로 명확히 하고 용암 표지선을 실제 붉은 흐름에 맞췄다. 안전 1의 도형 책상을 기존 삽화로 교체하고 머리 보호·책상 다리 잡기 자세를 정렬했다.
