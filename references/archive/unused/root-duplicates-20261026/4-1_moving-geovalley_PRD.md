- **Title:** 움직이는 지오밸리
- **English working title:** Moving GeoValley

- **Description:** A five-stage interactive Grade 4 science game where students investigate changing landforms, volcanoes, igneous rocks, and earthquake safety through hands-on simulations.
- **대상:** 초등학교 4학년
- **교과:** 과학 — 땅의 변화

- **작성일:** 2026-08-24

## 1. 제품 한 줄 정의

「움직이는 지오밸리」는 학생이 **땅의 변화를 눈으로 확인하는 데서 끝나지 않고, 직접 조건을 조절하고, 3D 지형과 암석을 관찰하고, 시간 변화를 되짚고, 증거를 표시하고, 실제 상황에서 안전 행동을 수행**하면서 흐르는 물·화산·화성암·지진을 하나의 과학 탐사 이야기로 연결하는 초등 4학년 과학 학습 게임이다.

---

## 2. 제품 목표

이 제품은 객관식 디지털 문제집이 아니다. 핵심 학습 루프는 다음과 같다.

**예상 → 조작 → 변화 관찰 → 증거 수집 → 관계 판단 → 실제 상황 적용 → 수정/재도전**

제품 성공 기준은 다음 질문에 분명히 답할 수 있어야 한다.

> “왜 굳이 태블릿으로 해야 하나?”

제품 수준의 답은 다음과 같다.

1. 3D 지형을 회전·확대하며 2D 사진에서 놓치기 쉬운 변화를 관찰한다.
2. 물을 흘리기 전 예상 지점을 직접 표시하고, 실험 전·중·후를 시간 막대로 비교한다.
3. 암석을 360° 회전·핀치 확대하고 자신이 발견한 특징에 관찰핀을 꽂는다.
4. 정답을 누르기 전에 학생 자신이 수집한 증거를 제출해야 판단이 완료된다.
5. 화산도시의 시간축을 움직이며 분출 직후와 장기적인 영향을 구분한다.
6. 지진 장면에서 캐릭터 이동, 몸 보호, 대피 경로 그리기 등 순차 행동을 수행한다.
7. 학생의 실제 오답·재시도 기록이 마지막 개인별 복구 미션으로 다시 사용된다.
8. 같은 드래그앤드롭을 10화면 반복하지 않고 화면마다 다른 조작 문법을 사용한다.

## 3. 교육과정 근거

### [4과11-01]
**흐르는 물의 작용과 강 주변 지형의 특징을 관련지을 수 있다.**

게임 반영:
- Screen 03에서 3D 흙 언덕에 물을 흘려 침식·운반·퇴적의 흔적을 직접 표시한다.
- Screen 04에서 상류→하류를 이동하며 강폭·경사·돌·모래/흙 등의 증거를 수집한다.
- 단순 “상류/하류 맞히기”가 아니라 최소 2개 이상의 관찰 증거를 근거로 판단한다.

### [4과11-02]
**화산의 의미와 화산 활동으로 나오는 물질을 알고, 화산 활동을 모형으로 표현할 수 있다.**

게임 반영:
- Screen 05에서 화산 활동 모형을 구성하고 작동한다.
- 화산 암석 조각·화산재·용암·화산 가스를 관찰 결과와 연결한다.
- 모형과 실제 화산 시뮬레이션을 화면 분할로 비교하여 공통점과 차이점을 구분한다.
- 3D 지하 단면은 화산 발생 원인을 설명하는 용도가 아니라 마그마/용암과 분출 장면의 위치 관계를 관찰하는 보조 화면으로 제한한다.

### [4과11-03]
**화성암을 관찰하고 분류할 수 있다.**

게임 반영:
- Screen 06에서 현무암과 화강암 표본을 회전·확대·나란히 비교한다.
- 색과 알갱이 크기를 중심으로 관찰 증거를 수집한다.
- 이름 선택만으로 완료되지 않고 관찰 근거 2개 이상을 함께 제출해야 한다.
- 현무암의 구멍은 일부 표본의 관찰 특징으로만 사용하고, 모든 현무암의 필수 판별 기준으로 사용하지 않는다.
- 초등 4학년 범위에서 현무암과 화강암 외 다른 화성암 분류를 평가하지 않는다.

### [4과11-04]
**화산 활동과 지진이 우리 생활에 미치는 영향을 조사하여, 대처 방법을 실천할 수 있다.**

게임 반영:
- Screen 07에서 화산도시의 시간 변화를 조사하여 피해와 이로운 영향을 구분한다.
- Screen 08에서 관찰 자료를 비교하고 안전에 필요한 정보를 정리한다.
- Screen 09에서 집·학교·건물·야외·해안 등의 지진 상황을 분기형 시뮬레이션으로 수행한다.
- 지진의 발생 원인을 설명하거나 판 구조론을 선행 학습시키지 않는다.

## 5. 세계관

Science World의 지구·우주 지역에 **지오밸리(GeoValley)**가 있다. 강, 협곡, 화산지대, 암석 연구소, 마을과 관측센터가 연결된 거대한 자연 연구 지역이다.

어느 날 지오밸리의 변화 기록에 여러 이상 신호가 발생한다. 학생은 **지오밸리 변화 조사원**이 되어 현장을 조사한다.

세계관은 학습을 가리는 긴 서사가 아니라 다음 질문을 연결하는 최소한의 맥락으로 사용한다.

- 왜 이 땅의 모습이 달라졌을까?
- 이 흔적은 흐르는 물의 어떤 작용과 관련 있을까?
- 모형에서 본 화산 활동과 실제 화산은 무엇이 같고 다를까?
- 이 암석의 정체를 어떤 증거로 설명할 수 있을까?
- 화산과 지진이 생활에 영향을 주는 상황에서 어떻게 판단하고 행동해야 할까?

## 6. 핵심 학습 루프

```text
현장 이상 발견
  ↓
예상/가설 표시
  ↓
학생 직접 조작
  ↓
시간/공간 변화 관찰
  ↓
증거 핀·관찰 태그·경로 기록
  ↓
근거 기반 판단
  ↓
피드백
  ↓
재실험/다른 조건
  ↓
탐사 기록 저장
```

정답은 가능한 한 마지막에 판정한다. 학생이 먼저 관찰하고 스스로 표시한 정보가 이후 판단에 실제로 사용되도록 한다.

## 8. Stage 1 — 흐르는 강

### Screen 03: 흐르는 물 실험실

학생 행동:
1. 물이 흐르기 전에 가장 많이 변할 것 같은 지점을 예측핀으로 표시한다.
2. 3D 흙 언덕을 제한 회전하여 다른 각도에서 관찰한다.
3. 물의 시작 위치를 선택하고 실험을 시작한다.
4. 흙 입자의 이동과 지형 변화를 관찰한다.
5. TIME SCAN으로 실험 전·중·후를 오간다.
6. 깎인 곳, 이동 흔적, 쌓인 곳을 직접 표시한다.
7. 표시한 현상과 침식·운반·퇴적을 연결한다.

설계 원칙:
- 물의 실제 유체 해석이 아니라 교육용 결정론적 시뮬레이션을 사용한다.
- 물의 양을 탐색 변수로 제공하더라도 정량 법칙을 학습 목표로 평가하지 않는다.
- 처음부터 침식·운반·퇴적 라벨을 표시하지 않는다.

### Screen 04: 강의 흔적 판독실

학생 행동:
1. 상류에서 하류로 이어지는 긴 강 지형을 스와이프해 이동한다.
2. 여러 관측 지점에서 강폭, 경사, 돌의 모습, 모래·흙 등을 조사한다.
3. 최소 2개 이상의 증거핀을 수집한다.
4. 증거를 근거로 상류/하류의 특징을 판단한다.
5. 흐르는 물의 작용과 강 주변 지형 특징을 관계선으로 연결한다.

완료 기준:
- 상류/하류 이름만 맞혀서는 완료되지 않는다.
- 최소 4개 관측 지점 조사 + 각 판단에 2개 이상의 증거가 필요하다.

## 9. Stage 2 — 불의 산

### Screen 05: 화산 모형 연구소

학생 행동:
1. 화산 활동 모형을 구성한다.
2. 어떤 현상이 나타날지 먼저 예상한다.
3. 분출 시작 후 일시정지·느리게·빠르게 보기를 사용한다.
4. 나온 물질의 상태와 모습을 관찰한다.
5. 실제 화산 시뮬레이션과 모형을 좌우 분할 비교한다.
6. 공통점과 차이점을 직접 연결한다.
7. 화산재, 화산 암석 조각, 용암, 화산 가스를 관찰 결과와 연결한다.

3D 지하 보기:
- 화산체를 회전한다.
- “지하 보기”에서는 단면을 열어 지하의 마그마와 지표에서 흘러나오는 용암의 위치를 관찰한다.
- 판 경계, 맨틀 대류, 화산 발생 원인을 설명하지 않는다.

---

## 10. Stage 3 — 암석 연구소

### Screen 06: 암석 감정 연구실

표본:
- 현무암 3개, 화강암 3개 정도의 변형 표본을 사용하여 단일 이미지 암기를 피한다.

도구:
- 360° 회전
- 핀치 확대
- 비교 트레이
- 관찰핀
- 특징 태그

핵심 증거:
- 색
- 알갱이의 크기
- 표면에서 관찰되는 차이

완료 방식:
1. 표본을 자유 관찰한다.
2. 자신이 발견한 위치에 관찰핀을 꽂는다.
3. 현무암/화강암을 분류한다.
4. 자신의 관찰 기록에서 근거 2개를 선택하여 제출한다.

정확성 가드레일:
- “현무암은 반드시 구멍이 있다”를 정답 규칙으로 사용하지 않는다.
- 실제 표본의 다양성을 반영한다.
- 밝기만으로 단독 판정하지 않고 알갱이 크기 등의 관찰 근거와 함께 사용한다.

---

## 11. Stage 4 — 화산도시

### Screen 07: 시간이 흐르는 화산도시

도시 요소:
- 마을
- 농경지
- 공항/교통 구역
- 관광·온천 구역
- 에너지/연구 구역

시간 단계:
- 분출 직후
- 시간이 지난 뒤
- 오랜 시간이 지난 뒤

학생 행동:
1. 시간 슬라이더를 움직인다.
2. 같은 장소가 시간에 따라 어떻게 달라지는지 조사한다.
3. 피해, 이로운 영향, 시점에 따라 달라지는 영향을 구분한다.
4. 판단 근거를 지도에 연결한다.

정확성 원칙:
- 화산재가 언제나 즉시 농사에 이롭다고 표현하지 않는다.
- 피해와 이로운 영향을 같은 시간축에서 단순 동시 발생으로 오해시키지 않는다.

### Screen 08: 화산 관측센터

학습 역할:
- 화산 관측 기술 자체를 심화 학습시키는 페이지가 아니다.
- 여러 관찰 자료를 비교하고 생활 안전에 필요한 정보를 선별하는 확장형 조사 페이지다.

학생 행동:
1. 지오밸리의 관찰 지점을 선택한다.
2. 분출 전후 이미지·기록·간단한 관측 자료를 비교한다.
3. 생활에 영향을 주는 변화 신호를 표시한다.
4. 주민에게 전달해야 할 정보를 중요도 순으로 정리한다.

완료 기준:
- 3개 이상의 자료를 확인
- 서로 다른 자료 2개 이상을 근거로 정보 카드 완성

## 12. Stage 5 — 흔들리는 도시

### Screen 09: 지진 대응 시뮬레이터

상황 풀:
- 집
- 학교
- 건물 안
- 집 밖/야외
- 산 또는 해안

한 플레이에서 3개 상황을 랜덤 제시하고, 완료 후 나머지 상황을 재도전할 수 있다.

예시: 학교
1. 흔들림 시작
2. 책상 아래로 이동
3. 머리와 몸 보호
4. 책상 다리 잡기
5. 흔들림 멈춤 확인
6. 질서를 지켜 대피
7. 안전한 경로로 운동장 이동

입력:
- 캐릭터 드래그/탭 이동
- 보호 행동 버튼
- 선택적 press-and-hold 연출
- 행동 순서 카드
- 손가락으로 대피 경로 그리기

접근성:
- long press는 몰입용 입력일 뿐 유일한 완료 방식으로 사용하지 않는다.
- 동일 행동을 큰 버튼 탭으로도 수행할 수 있다.

실패 피드백:
- “틀림” 표시만 하지 않는다.
- 해당 행동이 위험한 이유를 장면 안에서 짧게 시각화한다.
- 재시도 시 정답 경로 전체를 자동 공개하지 않는다.

## 13. Final — 지오밸리 복구 작전

Screen 10은 Screen 01과 같은 지오밸리 3D 장면을 재사용한다.

### 적응형 복구 미션

플레이 중 누적된 오개념/실수 태그에서 최대 3개를 선택한다.

예:
- `erosion_deposition_confusion`
- `upstream_downstream_evidence`
- `volcano_material_state`
- `model_real_difference`
- `basalt_granite_grain`
- `volcano_impact_time`
- `earthquake_action_sequence`

각 태그는 객관식이 아닌 짧은 수행형 복구미션으로 변환한다.

### 결과

- 흐르는 물 조사 완료
- 강 지형 증거 분석 완료
- 화산 모형 비교 완료
- 암석 표본 감정 완료
- 화산 영향 조사 완료
- 지진 대응 훈련 완료

학생 결과는 점수 하나보다 아래 역량 기록 중심으로 보여준다.

- 관찰
- 증거 분석
- 관계 판단
- 안전 실천

선택적으로 결과 카드를 PNG로 저장할 수 있다. 이름 입력은 결과 생성 직전에 선택적으로 받고 저장 데이터에는 포함하지 않는다.

## 14. 보상 및 선택 구조

첨부된 점수 카드 게임의 **“여기서 멈출까, 더 도전할까?”**라는 선택의 재미만 벤치마킹한다.

각 Stage 완료 후 오버레이:
- **기록 확정:** 현재 진행을 안전하게 저장하고 다음 Stage로 이동
- **추가 조사:** 더 어려운 관찰/추리 1개에 도전하여 희귀 탐사표본 또는 배지 획득

원본 게임의 폭탄, 핵폭탄, 점수 뺏기, 팀 점수 교환, 화면 구성은 사용하지 않는다.
추가 조사 실패 시 핵심 학습 진행도는 잃지 않는다.

## 22. 벤치마킹 원칙

### 참고한 학습 구조
1. `4-1 3단원 정리 게임(고양이 폭탄).pptx`
   - 참고: 정답 뒤 “멈출지 더 도전할지” 결정하는 선택감
   - 변환: 학습 손실 없는 “기록 확정 / 추가 조사” 선택
   - 미사용: 폭탄·핵폭탄·점수 탈취·원본 카드 UI

2. `첫번째 추리) VR 자료.pdf`
   - 참고: 공간을 탐색하며 단서를 찾는 구조
   - 변환: Screen 01의 지오밸리 이상 신호 탐색
   - 미사용: 호텔·황금 화산석·QR·원본 스토리

3. `세번째 추리) 화성암 진술 자료.pdf`
   - 참고: 암석의 출처와 특징을 근거로 판단하는 증거 추리
   - 변환: Screen 06의 연구 표본 감정과 근거 제출
   - 미사용: 용의자·인물·진술문·원본 설정

4. `아이스크림_4-1-3_땅의변화_5,6차시_화산 활동 모형을 만들자!.pptx`
   - 참고: 화산 활동 모형 제작, 화산 분출물, 실제 화산과 모형 비교
   - 변환: Screen 05의 3D 모형 실험과 분할 비교
   - 미사용: 슬라이드 화면·문구·레이아웃

5. `아이스크림_4-1-3_땅의변화_9차시_지진은 우리에게 어떤 영향을 줄까_나무쌤이_콩순추가.pptx`
   - 참고: 집·학교·건물·야외·산/해안 등 장소별 대처 순서
   - 변환: Screen 09의 분기형 안전 시뮬레이션
   - 미사용: 원본 슬라이드 디자인과 퀴즈형 전달

6. 사용자가 제공한 화성암 실물 사진
   - 참고: 현무암·화강암의 실제 표본은 색·질감·형태가 한 가지가 아님
   - 변환: 표본 1개 암기를 피하고 여러 변형 3D 표본 사용
