# 실험 화면·조작·배속 정리 검증

2026-11-08. 사용자가 요청한 한 화면 배치, 반복 안내 정리, 다음 행동 안내, 판단을 대신하지 않는 배속 자동재생의 구현 기록이다. 기존 작업 중인 변경과 학생 저장 형식을 보존했다.

## 바뀐 동작

- 화면 높이가 충분하면 하단에 조작을 배치하고, 낮은 가로 화면에서는 오른쪽에 배치한다. 페이지와 조작 영역의 내부 스크롤을 없앴다.
- 실험 진행 수를 제목 옆 한 곳에 표시한다. 단계 이름의 반복 표시와 완료 배지를 줄였고, 힌트·수첩·개념 영상·획득 도구·3D 보조 도구는 상단 ‘도구’ 메뉴에 모았다.
- 안내는 현재 행동 위주로 짧게 쓴다. 긴 관찰 결과가 작은 화면의 조작을 밀어내면 안내만 전체 너비로 펼친다. 문장을 잘라 숨기지 않는다.
- 18개 관찰·반복 조작 단계의 자동재생에 0.5/1/2/3배속을 제공한다. 방문 간격과 물 흐름·이동 등 실험 움직임에 같은 배속을 적용한다.
- 자동·수동 관찰 뒤에는 직접 선택할 버튼, 완료 뒤에는 다음 버튼을 강조한다. 정답·분류·안전 위치·경로는 직접 판단하며 자동으로 다음 페이지를 넘기지 않는다.
- 재생 중 속도 변경은 이어서 적용한다. 직접 조작, 힌트·모달, 창 비활성화, 화면 전환은 재생을 멈춘다. 완료한 실험 재생은 기존 증거를 다시 쓰지 않는다.

## 확인 결과

| 검증 | 결과 |
|---|---|
| 기본 30장면 × 5크기 | 150/150, 페이지·패널 스크롤/조작 가림/48px 미달/런타임 오류 0 |
| 실제 완주 기록으로 재방문 30장면 × 5크기 | 150/150, 동일 검사 통과 |
| 힌트·개념 영상·공통 화면 | 450/450, 런타임 오류 0 |
| 학생 모드 전체 진행 | 발견 30개, 개념 영상 10회, 보상 5개, 최종 도전 3개, 엔딩·인증서·새로고침 복원 통과 |
| 브라우저 배속·중단·재생·판단 분리 | 9개 시나리오 통과. 동일 시간의 3배속 진행량이 1배속의 약 3배임을 실측 |
| production 기본 화면 | 667×375와 1280×800의 60/60 통과 |
| production 배속·중단·저장 복원 | 9개 시나리오 통과 |
| 자동재생 단위 회귀 | 실제 재생 컨트롤러를 사용한 37/37 통과 |
| 전체 단위 회귀 | 104/104 통과 |
| 구문·공백·빌드 | `npm run check`, `git diff --check`, `npm run build` 통과 |

5크기는 667×375, 915×412, 1024×768, 1280×800, 1920×1080이다. 이 Mac의 Chrome과 격리된 Playwright 브라우저에서 검사했다. 실제 학교 태블릿·Safari·200% 텍스트 확대는 이번에 실측하지 않았다.

기본·완료 화면은 각각 마지막 레이아웃 변경 후 검사했고, 마지막 변경인 수동 관찰 뒤 버튼 강조는 production에서 별도로 확인했다. 실험·표본·도시·안전 장면의 대표 캡처도 직접 열어 확인했다. 전수 좌표 검사를 모든 픽셀의 시각 검수로 해석하지 않는다.

## 파일과 근거

주요 구현은 `src/main.js`, `src/adventure/index.js`, `src/adventure/playback.js`, `src/adventure/observation-tour.js`, `src/rounded-ui.css`에 있다. 강·암석·도시·안전의 현재 안내와 재생 상태 연결도 다듬었다. `scripts/autoplay.test.mjs`는 자체 모의 재생 타이머 대신 실제 공통 재생 컨트롤러를 사용한다.

새 검증 명령은 `npm run check:activity`, `npm run check:playback`이다. 외장 SSD의 `.work/activity-fit-20261108/`에 `final-layout`, `completed-layout`, `ui`, `student-flow`, `playback`, `production-layout`, `production-playback` 결과 JSON과 캡처가 있다. `docs/design/ACTIVITY-FIT-20261108.md`에 배치 계약을 기록했다.

외장 T7 Shield의 USB·External·읽기/쓰기 상태와 여유 공간을 확인했다. 모든 이번 작업 산출물, 임시 브라우저 프로필, npm/도구 캐시와 로그는 외장 경로를 사용했다. Codex 앱 자체의 자동 저장 경로를 이전했다는 뜻은 아니다.
