# 지오밸리 탐험 고도화 · 2026-10-18

## 이번 구현 방향

공유 대화 `https://chatgpt.com/share/6ad4c11d-7be4-83ec-bf70-f43510a36619`를 실제 브라우저에서 열어 전체 대화를 확인했다. 5 Mission × 2 Screen, Evidence, World Change, 마지막 새 상황 해결, 인증서 구조를 유지한다. 배경은 글자 없는 가로형, 일관된 캐릭터 시트를 사용한다. 비교 프로젝트 ‘우당탕 힘 실험실’의 이미지 중심 무대와 캐릭터 연결감을 참고하되 기존 게임의 캐릭터·자산을 복제하지 않는다.

### 학생의 목표

“리버와 다섯 곳을 조사해서 꺼진 관찰탑을 다시 연결하자.” 자연현상을 없애는 게임이 아니다. 자연을 관찰해 기록을 복원하는 게임이다. 장소마다 리버가 직접 실험·이동에 참여하며, 관찰한 증거가 탐험 가방과 마지막 문제에 남는다.

### 화면과 진행

- 태블릿 가로형 1280×800, 1024×768 우선. 한 화면에 한 조작 목표, 짧은 힌트, 조작 무대, 진행 구슬 3개. 기본 화면 스크롤 없음.
- 첫 화면부터 실제 탐험 지도. 길 위 이동 → 장소 도착 → 의뢰·얻을 도구 확인 → 2개 활동(각 3단계) → 보상 획득 → 지도 복구.
- 선택지 탭 대신 실제 이미지·도구 끌기, 문지르기, 손잡이 조작, 시간 비교, 길 그리기. 키보드 대체 조작은 도움 패널에 둔다.
- 단순 대기시간으로 분량을 늘리지 않는다. 예상–실험–관찰–비교–새 상황 적용의 서로 다른 행동으로 구성한다. 목표 5~8분/장소는 설계 예상이며 아동 사용성 시험으로 검증해야 한다.

## 보상 원칙

기록 획득마다 작은 빛 조각, 활동마다 관찰 도장, 장소마다 도구 1개와 지도 연결등. 점수는 속도·반복 클릭·첫 정답에 주지 않는다. 모든 단계는 실패 감점 없이 고쳐서 해결한다. 이미 완료한 기록은 보상을 중복 지급하지 않는다. 도구는 이후 관찰 도움 또는 마지막 기록 사용과 연결한다. 완료 장소도 재탐험 가능하다.

## 기술 범위

Phaser 3.90.0을 프로젝트 안에 고정 보관해 외부 CDN 없이 실행한다. 캔버스는 장면·캐릭터·입력·애니메이션, DOM은 짧은 안내·내비게이션·접근성 보조를 담당한다. 기존 저장 키와 관찰 기록 구조를 보존하며 새 단계 진행은 각 draft.data.adventure에 추가한다. 기존 소스는 `.work/before-adventure-20261018`에 보관했다. 자동 배포는 요청 범위에 없다.

## 중단 작업 복구 및 검증 · 2026-10-18

- 지도와 10개 활동을 학생 모드로 진행해 **30/30 발견, 5/5 도구**, 기록탑의 대표 관찰 선택, 새 물길·암석·안전길 응용 도전 3개, 엔딩과 인증서까지 확인했다. 브라우저에 남은 진행은 이 검증에서 만든 기록이다.
- 지도가 준비되기 전에 장소를 눌렀을 때 입력을 잃던 문제를 수정했다. 지도가 준비되면 요청한 이동을 시작한다.
- 잘못된 단계 저장 자료는 정상 구조로 복구하고, 앞 단계가 빠진 상태에서는 뒤 단계 완료를 인정하지 않는다. 30개 발견과 중간 작업을 저장·복원하는 회귀 검사를 추가했다.
- 관찰 기록에 활동 안의 단계를 함께 남겨 수첩과 엔딩의 재탐구가 정확한 관찰 단계로 돌아가게 했다. 이전 기록은 보존한다.
- 안전길의 버튼 입력과 실제 포인터 그리기를 분리했다. 도움창을 닫는 포인터 이벤트가 경로 끝에 잘못 붙던 오류를 수정하고, 같은 오류를 재현하는 테스트와 실제 그리기 테스트를 추가했다.
- 마지막 화면의 세로 스크롤과 인증서 보조 버튼의 글자 대비를 복구했다. 1280×800과 1024×768 가로 화면에서 경로 활동·지도·인증서를 확인했다.
- `npm run check`, **`npm test` 36개**, `npm run build` 통과. 빌드 미리보기의 실행 파일 70개는 HTTP 200 및 원본과 동일한 크기를 확인했고, Git 설정·README·설계 문서 경로는 HTTP 404를 확인했다. 학생 모드 전체 진행에서 브라우저 콘솔 오류는 없었다.
- Phaser의 공식 MIT 라이선스는 `public/assets/vendor/Phaser-LICENSE.md`, Jua 글꼴 라이선스는 `public/assets/fonts/Jua-OFL.txt`에 보관한다. 새 지도·도구·포즈 제작 기록은 `public/assets/generated-manifest.json`에 있다.
- 검증 화면은 로컬 `.work/verification-20261018/`에 보관한다. 원본 이미지·ZIP·백업·빌드 결과는 로컬에 유지하며 Git에서는 제외한다.

실제 아동 사용성·목표 학습 시간·현장 대피 훈련과의 연결은 별도 수업 검증이 필요하다. 인증서의 브라우저 인쇄 대화상자와 실제 태블릿 터치는 이번 자동 검증에 포함하지 않았다.
