# 장별 시나리오 — 대화용 정리

2026-09-25. 확정 PRD가 아닌 사용자와 시나리오를 맞추기 위한 정리.

2026-10-12 추가 요구: 모든 페이지 좌측 상단 홈·이전, 우측 상단 소리·설정. 섹션 없는 단일 설정창의 관리자 전체 해금으로 모든 페이지를 한꺼번에 연다. 상세 명세와 미확정 재미·부분 3D 제안은 [공통 UI 및 몰입 고도화](UI_AND_ENGAGEMENT.md)를 참고한다. 현재의 2D 기준은 부분 3D 채택을 결정하기 전까지 유지한다.

## 기준과 버전 차이

1. 이번 사용자 요청을 우선한다: 자연 스테이지 선택 화면만 2.5D 픽셀아트 RPG, 그 외 2D 게임.
2. 공유 대화의 후반부 및 심화 설계서 v2를 기준으로 활동은 5개 미션 × 2장 = 10장으로 이해한다.
3. 예전 ZIP의 PRD/TRD/JSON은 메인과 엔딩을 포함한 전체 10장이다. 화면 번호, 3D 사용 정책, 런타임 배분을 그대로 가져오면 충돌한다.
4. 아래 2D 전환 방식과 MVP 범위는 이번 정리에서 제안하는 내용이다. 이전 대화의 확정 사항으로 취급하지 않는다.

## 전체 이야기

지오밸리의 자연 변화 기록 시스템에 오류가 생겼다. 학생은 변화 조사원이 되어 강, 화산, 암석, 화산도시, 지진 안전을 조사한다. 각 미션에서 얻은 기록 5개로 최종 기록 장치를 복구한다.

복구 대상은 자연현상 자체가 아니라 **관측 기록과 정보 시스템**이다. 강의 변화나 화산 활동이 사라져야 성공하는 이야기로 만들지 않는다.

메인 → 짧은 사건 소개 → 자연 스테이지 선택 맵 → 미션의 두 활동 → 조사 기록 획득 → 선택 맵에 복구 반영 → 다음 미션 → 기록 5개 제출·최종 복구 → 회상 엔딩 → 인증서.

## 화면 표현

- 메인: 로고와 자연 배경을 사용하는 2D 시작 화면.
- 자연 스테이지 선택: 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG 맵. 캐릭터가 강·화산·연구소·도시·안전센터 사이를 돌아다니며, 특정 장소에 들어가면 해당 장소의 2D 활동 화면으로 전환한다. 미션 완료 상태가 맵에 반영된다. 이 구조는 사용자 확인 완료.
- 활동 01~10: 기존 시안의 일러스트 배경 + 2D 상호작용 + CSS UI. 물체의 이미지에 입체감이 있어도 자유 회전하는 3D 장면은 도입하지 않는 방향.
- 최종 복구·엔딩·인증서: 2D. 별도의 3D 세계 화면을 추가하지 않는다.
- 장소의 두 활동을 마치면 캐릭터가 돌아다니는 스테이지 선택 맵으로 복귀한다. 키보드·터치 등 세부 이동 입력은 아직 미정이다.

## 미션 1 — 물이 남긴 흔적 / 수달 리버

의뢰: 강 주변 지형이 달라졌는데 변화 기록이 사라졌다.

**01 흐르는 물 실험실**
- 변할 것 같은 위치에 예상핀을 놓는다.
- 물을 흘리면 흙이 깎이고 이동하여 쌓이는 과정을 본다.
- 시간 막대를 앞뒤로 움직이며 전·중·후를 비교한다.
- 깎인 곳·이동 흔적·쌓인 곳을 각각 표시해 침식·운반·퇴적과 연결한다.
- 2D 전환 제안: 고정된 옆면/단면 지형, 물·흙 입자와 지형 단계 레이어로 변화 표현.

**02 강의 흔적 판독실**
- 긴 강 풍경을 좌우로 이동하며 상류부터 하류까지 관측한다.
- 강폭·경사·돌·모래 등 최소 4개 관측 지점을 조사한다.
- 각 판단에 증거 2개 이상을 연결하여 상류·하류 특징과 물의 작용을 설명한다.

보상: 강 변화 조사 기록. 지도에서 강 관측선 복구.

## 미션 2 — 화산의 신호를 읽어라 / 산양 마그

의뢰: 화산 모형 실험 기록과 실제 화산 자료가 뒤섞였다.

**03 화산 모형 구성실**
- 모형 재료를 준비하고 결과를 예상한 뒤 실험한다.
- 분출 장면을 멈추거나 느리게 보며 관찰한다.
- 2D 전환 제안: 작업대에서 단계별 구성, 분출 애니메이션, 필요한 단면 보기.
- 실제 수업에 맞는 모형 재료와 절차는 상세 설계에서 원자료로 확인해야 한다.

**04 모형과 실제 화산 비교실**
- 좌우에 모형과 실제 자료를 놓고 공통점 2개, 차이점 2개를 찾아 연결한다.
- 실제 화산 자료에서 용암·화산재·화산 암석 조각·화산 가스를 관찰한다.
- 모형에서 실제 용암이나 암석이 만들어진 것처럼 표현하지 않는다.

보상: 화산 활동 비교 기록. 지도에서 화산 연구소 점등.

## 미션 3 — 암석의 정체를 밝혀라 / 두더지 지오

의뢰: 표본 보관함에서 암석 이름과 관찰 기록이 사라졌다.

**05 암석 관찰실**
- 현무암·화강암 표본을 확대하고 나란히 비교한다.
- 색과 알갱이 크기를 관찰한 위치에 핀을 남긴다.
- 2D 전환 제안: 고해상도 표본 이미지, 돋보기, 앞·옆·뒤 사진 전환. 필요한 표본 이미지는 아직 확보되지 않았다.

**06 암석 감정 증거판**
- 앞 화면에서 남긴 관찰 기록으로 표본을 분류한다.
- 암석마다 서로 다른 관찰 근거 2개를 제출한다.
- 근거가 부족하면 해당 표본 관찰로 돌아간다. 구멍 유무 하나만으로 판정하지 않는다.

보상: 암석 감정 기록. 지도에서 표본 라벨·암석 데이터베이스 복구.

## 미션 4 — 도시의 변화를 기록하라 / 여우 타임

의뢰: 화산도시의 피해 기록과 오랜 시간 뒤의 변화가 섞여 있다.

**07 시간이 흐르는 화산도시**
- 시간 막대를 움직여 분출 직후, 시간이 지난 뒤, 오랜 시간이 지난 뒤를 비교한다.
- 공항·농경지·온천·마을의 같은 장소를 조사한다.
- 피해와 이로운 영향을 장소·시간의 근거에 연결한다.
- 2D 전환 제안: 고정된 도시 일러스트의 시간별 상태 전환과 장소 확대. 화산재가 즉시 농사에 이롭다는 연출은 피한다.

**08 화산 관측센터**
- 사진·기록·지도 등 자료를 확인한다.
- 서로 다른 자료 2개 이상으로 주민에게 알릴 내용을 뒷받침한다.
- 전달 정보의 우선순위를 정리한다. 전문 화산 예측이나 지진 원인 설명으로 확장하지 않는다.

보상: 화산도시 영향 보고서. 지도에서 도시 정보망 복구.

## 미션 5 — 안전 경로를 완성하라 / 다람쥐 세이프

의뢰: 안전센터의 지진 대응 행동 기록을 훈련으로 다시 채운다.

**09 지진 대응: 흔들리는 중**
- 현재 장소와 흔들림 상태를 확인한다.
- 학교 상황에서 캐릭터를 보호 위치로 이동시키고 몸을 보호하는 행동을 수행한다.
- 흔들리는 중과 멈춘 뒤의 행동을 구분한다.
- MVP 제안: 학교 상황 한 개를 먼저 완성하고 집·야외는 확장한다. 행동의 구체적 순서는 공식 안전 자료 확인 후 명세화한다.

**10 지진 대응: 흔들림이 멈춘 뒤**
- 2D 학교 평면도에서 대피 경로를 직접 그린다.
- 창문·낙하물 등 위험 구역을 통과한 부분만 표시하여 그 구간을 수정하게 한다.
- 캐릭터가 완성한 경로를 따라 안전 지점에 도착하면 기록을 얻는다.

보상: 지진 대응 훈련 기록. 지도에서 안전센터 복구 및 최종 장치 활성화.

## 최종 복구

- 조사 가방에서 5개 기록을 각각 맞는 슬롯에 제출한다.
- 연결 링을 돌리거나 채널을 연결한 뒤 중앙 장치를 가동한다.
- 2D 화면에서 각 지역의 기록이 복구되는 모습을 보여준다.
- 자신이 수행한 활동의 회상 연출 뒤 변화 조사 인증서를 제공한다.
- 이름 등은 출력 직전에 임시 입력하며 진행 저장에 포함하지 않는 기존 방향을 유지한다.

## MVP 범위 제안

- 메인, 선택 맵, 활동 10장, 기록 5개, 맵 변화, 최종 복구, 짧은 2D 엔딩, 인증서, 저장·이어하기.
- 미션마다 하나의 완결된 학습 흐름을 먼저 구현한다.
- 추가 표본·추가 안전 상황·보너스·탐구 스타일은 후속 범위로 제안한다.
- 새로운 PRD/TRD는 이 대화에서 시나리오와 표현 방식이 정리된 뒤 작성한다.

## 사용자 확인 사항

- 스테이지 선택 화면만 위에서 사선으로 바라보는 2.5D RPG 형태이며, 캐릭터가 돌아다니는 느낌이다.
- 해당 장소로 들어가면 2D 화면으로 전환한다.
- 이 확인은 이동 입력 방식이나 활동별 세부 규칙까지 확정한 것은 아니다.

검토 출처: 공유 대화의 표시된 본문, 심화 설계서 v2, 이전 PRD/TRD 관련 구간, 프롬프트 JSON의 공통 규칙, 원본 이미지 23개 및 ZIP 이미지 10개의 썸네일 시각 확인.
