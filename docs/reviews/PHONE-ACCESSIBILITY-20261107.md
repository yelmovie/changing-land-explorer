# 7 earthchange · 작은 화면 조작 추가 개선

2026-11-07. 기존 3/10 접근성 점수의 직접 원인인 작은 캔버스 드래그 의존을 추가 수정했다. 기존의 그림·애니메이션·직접 드래그는 유지하고, 같은 활동 상태와 판정 함수를 호출하는 **48px 이상/20px 텍스트 DOM 조작**을 추가했다. 관찰·선택·오답 거부를 생략하는 교사 넘기기가 아니다.

## 변경

- 화산6단계: 재료 고르기, 주사기 range, 구멍·흐른 길 조사, 분출물 선택, 비교 카드와 관찰 자리 선택. 기존 조립 순서·흐름 관찰·근거 조건 공유. 주사기 기존 약16.8px 손잡이를 직접 집지 않아도 진행 가능.
- 암석4개 관찰 장면: 세 위치 확대 선택, 특징4개 중 색/알갱이 직접 선택. 세 곳 관찰 전 특징 선택 잠금. 틀린 특징은 거부. 기존 약18.38px 특징 카드 대신 큰 선택 버튼 사용 가능. 이름 판단과 주문 버튼은 기존 유지.
- 강 현장: 관찰 위치 선택과 네 관찰 카드→상류/하류 연결, 마지막 모래 쌓임 선택. 틀린 위치 거부·기존 관찰 필요. 물 주기·시간·이름표의 기존 보조 경로 유지.
- 도시: 관찰 그림·까닭·할 일 카드와 안내판 자리 선택. 오답 및 앞 시기 관찰 누락 거부. 실내 창문 닫기, 마스크 위치 직접 선택과 선행 창문 조건 유지.
- 안전: 위험 표식 위치, 몸 보호 장소, 잡을 곳 선택. 오답·선행 보호·흔들림2.4초 대기 조건 유지. 경로 점찍기와 그리기는 기존 위험 판정을 유지한다. 점찍기 버튼을 누르면 출발점 하나만 준비하므로 작은 출발 원을 집을 필요가 없다. 경유점과 도착은 학생이 직접 선택한다.

## 판정 범위

C3의 확인된 작은 주사기/특징 카드 등 필수 드래그 FAIL은 동등한 큰 선택 경로로 해소했다. 그러나 모든 캔버스 경계·실기 손가락 제스처를 전수 보장한 것은 아니므로 **C3 WARNING**으로만 올린다. C11 전체 키보드, C20 남아 있는 그림 속 축소 텍스트, C19 실기 제스처·C25 확대 미검증을 유지한다. 따라서 접근성 **3→5/10**, 전체 첫 착수69→학습 개선70→추가 접근성 개선**72/100**. 휴대폰 전면 지원 완료로 표현하지 않는다. 1024px 이상 가로 태블릿·PC 권장은 유지하고 작은 화면의 대체 조작이 실질적으로 개선되었다고 판단한다.

## 작은 화면 완주 검사 경로 조정

915×412 최초 전체 포인터 검사는 기존의 작은 강 이름표 직접 드래그에서 세 기록을 모두 만들지 못해 반성 질문 버튼을 기다리다 실패했다(JS/HTTP오류0). 원본 실패는 `.work/phone-accessibility/dist-flow/flow-failure.json`에 보존했다. 검사를 실제 제공되는 큰 이름표 선택→원 누르기 경로로 변경했고 재실행 기록은 `dist-flow-retry/`다. 좁은 직접 드래그 자체가 편해졌다고 주장하지 않는다. 권장 태블릿1280×800의 기존 직접 조작 회귀 결과는 `dist-tablet-flow/`다.

작은 화면 두 번째 실행은 도시 기록에서 멈췄다. 이 화면은 기존 코드가 좁은 드래그를 의도적으로 끄고 카드 선택 모달을 제공하므로, 검사도 해당 실제 UI를 사용하도록 수정했다. 첫 두 실패 기록은 보존했다. 최종 작은 화면 실행은 `.work/phone-accessibility/dist-phone-final/`에 별도 저장한다.

**최종 작은 화면 완주 결과:** `.work/phone-accessibility/dist-phone-final/flow.json`의915×412 새 학생 기록에서30발견·10개념·5보상·3최종문제·엔딩·인증서·재접속 통과, JS/HTTP오류0. 자동화는 정답을 아는 포인터 스크립트이므로 실제 학생 수행이나 모든 단계의 실물 손가락 편의성 입증과는 구분한다. 별도 터치 시나리오는 위 각 집중 검사 결과를 따른다.
