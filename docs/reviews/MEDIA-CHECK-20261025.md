# 영상·소리 재점검 — 2026-10-25

- 개념 영상: 다섯 장소 × 활동 두 개 = 10편. 인트로와 엔딩은 별도의 동영상 파일 재생 흐름이 아니다.
- MP4 10개 FFprobe 검사: 모두 H.264, yuv420p, 1280×720, 8초. 파일별 약 24~97KiB. MP4 외 WebM·포스터가 함께 있다.
- 브라우저 검사: 1024×768과 1280×720의 10개 개념 영상 재생 시작, reduced-motion에서 수동 재생, 무음 상태를 확인했다. 10편 모두 전체 길이의 끊김을 실측한 것은 아니다.
- 영상 실패 시 포스터·텍스트 안내와 계속하기 경로, 닫기 시 src 정리가 구현되어 있다. 실패 주입의 모든 조합을 이번에 전수 재현하지는 않았다.
- 학생 발견 0개 상태에서도 첫 정리 영상이 열리는 것을 운영 화면에서 직접 재현했다. 완료한 활동만 열리는 다시 보기 규칙과 다르다.
