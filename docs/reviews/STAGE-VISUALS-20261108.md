# 암석·도시·안전 단계 시각 고도화 코드 검토

검토일: 2026-11-08. 이번 적용 직전 사본 `.work/responsive-20261108/applied/before-rocks.js`, `before-city.js`, `before-safety.js`와 현재 파일을 비교했다. Git diff에는 이전 동시 작업이 섞여 있으므로 이번 변경 판단의 기준으로 쓰지 않았다. 검토 중 확인한 암석 초점선 결함 한 줄을 통합 담당의 요청으로 수정했다.

## 확인한 변경

- `src/adventure/rocks.js`: 붓질 단계 밖의 관찰 NPC를 숨기고, 왼쪽 초점과 오른쪽 확대창 사이에 연결선을 추가했다. 확대창의 테두리·반사와 제목을 정돈하고 비교 도구 사용 시 연결선을 숨겼다.
- `src/adventure/city.js`: 분출 당시의 회색 구름 타원을 기존 화산재 이미지로 교체하고 목재 차단대를 그렸다. 시간 비교 마스크에 걸리던 본문 라벨을 제거했다. 농장 안내에 ‘아주 오랜 시간 뒤’를 명시했고 안내판의 전후 기록 제목·시간을 한 텍스트 흐름으로 합쳤다.
- `src/adventure/safety.js`: 학습자가 위험 표식을 놓은 뒤에만 해당 공간을 강조한다. 책상 다리를 잡기 전부터 대기 피드백을 표시하고, 실제 멈춤 상태와 함께 지운다. 길의 방향은 학습자가 저장하거나 그리는 선 위에만 표시하고 걸은 구간을 덧칠한다.

## 정적 검토와 Node 확인

재현 스크립트: `.work/responsive-20261108/review/static-review.mjs`. 결과: 같은 경로의 `static-review.json`. 프로젝트의 기존 Phaser 대역 하네스를 재사용해 실제 단계 setup과 입력 콜백을 실행했다.

- 암석·도시·안전의 `STAGE_ASSETS` 37개가 실제 외장 SSD 파일로 존재한다. 도시의 화산재 이미지 2개도 로딩 목록에 들어 있다.
- 새 안전 공간 표시는 초기 상태에서 없고 창문 표식을 올바르게 놓은 뒤에만 나타난다. 책장을 아직 선택하지 않았을 때 책장 증거가 생기지 않는다.
- 보호 대기는 책상 다리를 잡기 전에는 완료되지 않는다. 잡은 뒤 2,400ms에 `stopped`가 되고 진동 피드백이 사라진다. 일반/동작 줄이기 두 설정 모두 확인했고 동작 줄이기에서는 책상이 움직이지 않는다.
- 일반 학습자의 안전길 화면은 정답 경로를 미리 채우지 않는다. 방향 표시는 이미 있는 학습자 선에만 붙는다. 걷기 일시정지·재개 후 경로와 검증 서명이 보존된다.
- 시간 비교 화면의 피해/시간 변화 라벨은 분할 마스크 안의 텍스트에서 제거된다. 관찰 완료·카드 판정·안내판·안전의 기존 DOM 대체 조작과 저장 코드는 적용 직전 사본과 비교해 보존됐다.
- 새 그래픽은 장면 소유 객체이고 새 타이머/이벤트 구독은 추가하지 않는다. 기존 단계 반환 훅과 호스트의 shutdown·pause 호출이 유지된다.

## 발견 사항

### 수정 완료 — P3: 암석 분류에서 카메라 왕복 시 초점선 재등장

위치: `src/adventure/rocks.js:84`. 새 표본 C 단계에서 `scanned:[0,4,5]`, `proofs:['dark','fine']`가 이미 저장된 상태로 열면 분류 선택지가 나오면서 렌즈와 초점선이 숨겨진다. 카메라를 눌러 비교했다가 다시 누르면 렌즈는 숨겨진 채 초점선만 다시 나타난다. Node 실행에서 `guide.visible`이 `false → false → true`로 바뀌는 것을 확인했다.

카메라 콜백을 `focusGuide.setVisible(!compare&&!traysMade)`로 한 줄 수정했다. 판정·저장에는 영향이 없는 시각 결함이다. 같은 Node 재현 스크립트를 다시 실행해 카메라 왕복 후에도 초점선이 계속 숨겨짐(`visibleAfterReturningToSample:false`)을 확인했다. 다른 검증 항목도 모두 다시 통과했다.

## 통합 검증과 남은 확인

- 초점선 한 줄 수정 전에 통합 담당에게 전달받은 최신 전체 단위 테스트 결과는 101/101 통과다. 이 검토에서는 같은 전체 테스트를 중복 실행하지 않고 수정 후 위 재현 스크립트만 다시 실행했다.
- 브라우저·스크린샷·반응형 시각 검증은 `responsive_qa` 담당이다. 이 문서는 실제 폰트 폭, 캔버스 글자 잘림, 아이콘 겹침의 시각 통과를 주장하지 않는다.
- 안전길의 폭 70인 ‘넘어진 책장’과 폭 45인 ‘전신주’ 라벨을 QA에 별도 확인 요청했다. 1280 화면의 실제 Phaser bounds와 캡처 확인 결과 점선 안전 여백 밖으로 나가는 부분은 최대 약 2 gameunit(1.7 CSSpx)이고 경로를 의미 있게 가릴 정도는 아니라는 답을 받았다. 1920 화면 최종 검증은 QA가 이어간다.
- 최종 빌드는 통합 담당이 한 번 실행할 예정이다. 이 검토에서는 설치·다운로드·이미지 생성·빌드·브라우저 실행을 하지 않았다.
- 한 줄 수정 후 상위 AGENTS 규칙에 따라 `graphify update .`를 실행했고 AST 갱신이 정상 완료됐다(4,502 노드, 8,177 간선). 의미 기반 라벨 갱신이나 외부 API 호출은 실행하지 않았다.

모든 검토용 파일과 결과는 외장 USB T7 Shield에 저장했다. 볼륨의 외장 연결·쓰기 가능 상태·여유 공간을 먼저 확인했고 임시/캐시 환경도 프로젝트 외장 경로로 지정했다.
