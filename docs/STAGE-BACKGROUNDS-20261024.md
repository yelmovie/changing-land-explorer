## 적용과 원본

- 배포 이미지: `public/assets/art/*-v2.webp`, 1600×900 WebP. 전체 목록과 바이트 수는 `public/assets/art/stage-backgrounds.json`.
- 원본 PNG: `assets/raw-png/stage-backgrounds-20261024/`. 기존 배경과 이전 원본을 덮어쓰거나 삭제하지 않았다.
- `src/stage-art.js`에서 기존 논리 에셋 키를 새 배경으로 연결한다. Phaser 화면, 양옆 여백, 지도 미션 미리보기, 관찰 수첩이 같은 매핑을 사용한다.
- 저장 키·완료 판정·학생 기록의 에셋 이름은 유지했다. 따라서 기존 관찰 기록도 새 그림으로 열린다.
- 암석 화면의 예전 작업대 덮임을 제거하고, 화산 비교·주민 안내 화면의 패널은 글자를 읽으면서 배경을 볼 수 있도록 조정했다.

## 프롬프트 조건

공통 조건은 지도와 같은 입체 손그림, 한 이미지에 한 환경, 16:9, 글자·UI·등장인물 없음, 조작 영역은 비우기다. 장소별 차이는 위 표의 소재와 색으로 지정했다. 강 관찰과 화산 분출물, 도시의 공항·농장·온천, 학교의 창문·책장·책상은 기존 관찰 좌표를 프롬프트에 포함해 생성 후 다시 확인했다.

## 위치·가독성 보정

- 강 상류·하류 네 관찰 지점, 화산 네 분출물, 도시 세 장소가 새 그림과 대응하는지 실제 캔버스로 확인했다.
- 하류 물길의 돋보기 중심은 새 그림의 넓은 물줄기에 맞춰 원좌표 (625,400)으로 이동했다. 수첩도 같은 관찰 위치를 표시하며 이전 저장 원본은 수정하지 않는다.
- 교실의 오른쪽 책상 다리는 새 그림의 x=960에 맞춰 표시·드롭 영역·손 위치를 함께 이동했다. 몸을 보호하는 위치와 학습 조건은 유지했다.
- 배경 위에 겹치는 실험 설명과 표본 이름은 밝은 읽기판을 적용했다.
- 안전 경로는 충돌 판정과 대응해야 하므로 통로·위험 영역의 코드 도형을 유지했다.
