# 개념 영상과 교실 UI 개선 (2026-10-22)

5개 장소 × 2개 활동마다 8초 개념 영상을 연결했다. 각 활동의 세 발견을 마치고 다음 버튼을 누르면 핵심 개념을 확인한 뒤 다음 활동이나 도구 보상으로 진행한다. 영상의 닫기·Escape는 활동에 머무르며, 반복 재생과 건너가기가 가능하다. 평소에는 자동 재생하고 동작 줄이기 설정에서는 직접 재생한다.

## 영상 컷 설계

정적인 정면 전체 구도에서 원인 → 변화 → 결과를 0~2.67초 / 2.67~5.33초 / 5.33~8초로 보여 준다. 카메라 이동은 없고, 끝은 결과 구도를 유지한다. 인물 생성 대신 직접 작성한 일관된 개념 도형을 사용한다. 마지막 두 안전 영상은 책상 아래 보호 자세와 위험을 피해 이동하는 경로를 보여 준다. 영상은 무음이며 큰 DOM 자막으로 설명한다.

| 영상 키 | 움직임·핵심 개념 |
|---|---|
| river-0 / river-1 | 침식·이동·퇴적 / 상류와 하류 |
| volcano-0 / volcano-1 | 붉은 물 모형의 흐름 / 실제 화산과의 차이 |
| rocks-0 / rocks-1 | 색·알갱이 확대 관찰 / 두 증거로 분류 |
| city-0 / city-1 | 분출 당시 피해와 아주 오랜 시간 뒤 변화 / 사실·까닭·안전 행동 |
| safety-0 / safety-1 | 책상 아래 머리·몸 보호 / 멈춘 뒤 안내 따라 안전하게 이동 |

1280×720, 24fps, MP4(H.264)+WebM(VP9)+WebP 포스터. 스크립트는 `scripts/concepts/`에 있다. 실행 의존성은 추가하지 않았다. 재생 실패 시 핵심 문장을 모두 표시하고 진행할 수 있다.

재제작: `npm run concepts:render` (한 개만: `npm run concepts:render -- river-0`). 제작 도구는 `FFMPEG_PATH`, `SHARP_PATH`로 지정하며 기본값은 D:의 기존 로컬 설치를 재사용한다. 개발용 도구나 원본 프레임은 배포하지 않는다.

## UI와 상호작용

- 모든 공통 팝업을 중앙 정렬하고 제목·닫기는 고정, 본문만 필요한 경우 스크롤한다. 수첩·가방은 넓은 2~3열 배치다.
- 본문 기본 20px 이상, 화면이 큰 환경에서는 27px까지 확대한다. 제목 28~38px, 조작 영역 48px 이상을 기준으로 한다. 기존 잘게 나뉜 스타일은 `src/learning.css`가 공통으로 보정한다.
- 캔버스의 개념 글자는 실제 표시 배율을 고려해 확대한다. 리버의 지시는 한 문장 중심으로, 모은 전체 발견 수 중복 표시는 활동 화면에서 제거했다.
- 모든 30단계에 리버의 관찰 질문 → 사고 단서 → 조작 도움, 세 단계 힌트를 제공한다.
- 물체를 끌거나, 선택 후 목적지를 눌러 옮길 수 있다. 조작 도움의 큰 버튼은 여러 번 누를 수 있다.
- 암석 먼지는 붓뿐 아니라 표본을 손으로 직접 문질러 지울 수 있다. 안전길은 연속 선 그리기·점 찍기를 지원하며 동일한 위험 판정을 적용한다.
- 비교 시간에는 큰 처음·끝 버튼을 추가했다. 활동 완료 뒤에는 다음 행동을 주 버튼으로 보여 준다. 보조 도구는 배경의 학습 대상을 가리지 않도록 하단 조작 영역에 배치했다.
- CC0 효과음 출처와 파일별 원본은 `public/assets/audio/CREDITS.md`에 기록했다. 설정·상단 소리 스위치가 모든 효과음에 적용된다.

태블릿 사용의 의미는 같은 조건에서 물의 양을 바꾸고 되감아 비교하기, 표본을 확대·문질러 근거 모으기, 시간 손잡이로 전후 비교하기, 경로를 직접 만들고 실제 이동 결과를 확인·수정하는 데 있다. 각 활동의 관찰 기록과 기존 저장·보상 규칙을 유지했다.

## 검증

- JavaScript 문법 검사, 학습·저장·경로 회귀 검사 38개, 정적 빌드를 통과했다.
- Chrome 격리 브라우저에서 1024×768·1280×720·1920×1080의 30단계 화면, 각 힌트와 개념 재생, 설정·지도·최종 화면을 검사했다. 총 261개 항목을 통과했고 런타임 오류는 없었다. 팝업 중앙 정렬, 불필요한 팝업 스크롤, 터치 크기, 본문 크기, 활동 캔버스 잘림을 측정했다.
- 학생 모드로 30개 발견 → 개념 영상 10개 → 도구 보상 5개 → 새로고침 후 저장 복귀를 끝까지 검증했다. 안전길의 점 찍기는 선 그리기와 같은 위험 판정을 통과한다.
- 터치로 선택·놓기, 일반 모드 자동 재생, 동작 줄이기의 직접 재생, 시간별 자막, Escape 정리, 소리 끄기, 모든 영상 소스 실패 시 문장 대체도 확인했다.
- 동적으로 하단 조작부의 높이가 바뀌면 Phaser 부모 크기를 다시 맞춘다. 장면 종료 시 WebGL 컨텍스트를 명시적으로 반환해 많은 활동을 연속 방문할 때 자원이 쌓이지 않게 했다.
- 영상 10개는 모두 8.000초, 1280×720 H.264와 VP9 두 형식이다. 영상·포스터 전체 약 1.3MB, 효과음 전체 약 25KB로 로컬에 포함한다.
- 화면 검증은 Chrome 에뮬레이션이다. 실제 태블릿과 전자칠판의 밝기·스피커·터치 지연은 해당 기기에서 확인해야 한다.
