# 스테이지 반응형·학습 표현 보강

2026-11-08. 기존 그림체·학습 판정·저장·큰 화면의 전체 배경은 유지한다. 사용자가 각 스테이지의 글자/아이콘 겹침 수정과 학습 표현 고도화를 요청했다.

## 현재 확인한 문제

- 기존 DOM 전수검사는 네 해상도360/360이나, 667×375 도시 관찰의 실제 하단 조작이 예약된 높이를116px 넘어 실험을 가린다.
- 좁은 헤더가 잠긴 단계까지 세 칸을 예약해 긴 질문이 세 줄이 되고 실험 그림이 지나치게 작아진다.
- 공통 그림 카드의 아이콘 영역과 텍스트 영역을 다른 공식으로 계산해 위험 표식에서 글자와 그림이 겹칠 수 있다. 같은 콘텐츠 박스에서 두 영역을 분리한다.

## 화면 계약

- 높이가 충분한 화면: 질문은 상단, 안내와 조작은 하단. 실험은 실제 헤더·하단 높이 사이에 들어간다.
- 낮은 가로 화면: 왼쪽 실험과 오른쪽 조작 도크. 안내·도구·조작을 도크에 모으고, 내용이 길면 조작 칸 내부에서만 스크롤한다. 다음 버튼은 별도 행에 유지한다.
- 좁은 가로 헤더는 현재 단계 버튼을 남긴다. 현재 버튼을 누르면 전체 세 단계 이름·완료·잠금 상태를 큰 모달에서 확인하고 이동한다. 학습 잠금 규칙은 그대로다.
- 글자를 숨기거나 줄여서 겹침을 해결하지 않는다. 버튼48px, 도구 그림/아이콘은 독립 영역, 한글은 자연스럽게 줄바꿈한다. 확대/회전 뒤에도 실제 박스 크기를 다시 반영한다.
- 원래의 1200×640 학습 좌표, 직접 조작과 큰 대체 조작, 모션 감소·중단·재관찰을 유지한다.

## 단계별 표현

강은 같은 흙 입자의 깎임→이동→쌓임 연결, 화산은 모형 액체와 실제 분출물의 움직임 차이, 암석은 표본과 확대 영역의 연결, 도시는 같은 장소의 피해/복구/오랜 시간 구분, 안전은 위험/보호/대피 행동의 공간 피드백을 강화한다. 기존 이미지·재질을 재사용하며 정답 위치나 답 이름을 미리 노출하지 않는다.

## 병렬 소유·검증

공통 CSS·호스트는 주 작업자, 강/화산4파일과 암석/도시/안전3파일은 각각 전담, 브라우저 검증은 한 담당자만 사용한다. Claude 변경과 기존 학생 기록을 보존한다. 새 의존성·배포·외부 연락은 포함하지 않는다.

성공 조건: 네 해상도와1920×1080에서 확인된 글자/아이콘 겹침·하단 가림을 해소하고, 다섯 스테이지별 실측/대표 캡처·모달/터치·전체 완주로 기존 조건을 검증한다. 단순 DOM 좌표 검사와 실제 눈으로 확인한 범위를 나눠 기록한다.
