# 지오밸리 반응형 보강 · 2026-11-07

## 범위
기존 그림과 학습 규칙, 저장 데이터 구조를 유지하고 작은 가로 화면의 배치만 수정했다. 시작 시 Git 작업 트리는 깨끗했다. 커밋·배포·새 의존성 설치는 하지 않았다.

## 이미지 검토
현재 배경·암석 표본·주민·도구 이미지가 충분하며 추가 생성이 필요한 빈 장면은 찾지 못했다. 새 이미지 파일을 추가하지 않았다. 대신 마지막 암석 도전의 이미지와 선택지를 나란히 배치해 좁은 화면에서도 표본을 더 크게 볼 수 있게 했다.

## 수정
- `src/art.css`: 너비 800px 이하·높이 500px 이하 가로 화면에서만 적용하는 보강. 하단 안내와 도구의 잘못된 줄바꿈을 해소했다.
- 작은 화면의 힌트창 여백을 줄이고 개념 영상과 설명을 두 칸으로 배치했다. 667×375에서 재생 버튼을 실제로 누를 수 없던 문제를 해결했다.
- 기록탑 다섯 기록 선택을 한 줄로 배치하고 최종 도전의 다음 버튼을 화면 안에 유지했다. 아주 낮은 교사 시연 화면에서는 안내문 영역을 별도로 스크롤할 수 있다.
- `scripts/check-learning-ui.mjs`: 기본 검사에 667×375·740×360 추가. `CHECK_SHOTS` 정규식으로 특정 검사 화면을 저장할 수 있다.

- 변경 전 표준 6해상도: 540/540. 추가한 667×375에서 하단 도구 잘림 및 개념 영상 클릭 시간 초과를 재현했다.
- 최종 소스 검사: 667×375, 740×360, 768×1024, 1280×800, 915×412 총 450/450, 런타임 오류 0.
- 문법 검사 및 단위·회귀 테스트 75/75 통과. 로컬 build 통과, 149개 사전 캐시 파일.

- 로컬 빌드도 740×360에서 최종 3도전·엔딩·인증서·재접속 통과 (`.work/responsive-20261107-dist/flow.json`).
