# 지오밸리 이미지 적용 기록

2026-10-24. 사용자 요청: CSS·단순 도형으로 처리한 그림을 생성 이미지로 고도화하고 중단된 작업을 복구한다.

기존 지도·리버·자연 관찰 그림을 기준으로 숲의 녹색, 물의 청록색, 목재와 황동의 색을 맞췄다. OpenAI 내장 이미지 생성 도구를 사용했다. UI 글자·버튼·물의 이동·위험 판정·관찰 표식은 코드로 유지한다.

## 적용 규칙과 한계

- 실험의 입력 좌표·흐름 경로·완료 판정은 기존 기준을 유지했다. 두 물의 양을 비교할 때 같은 지형 이미지를 사용한다.
- 그림은 학습용 재현이며 실제 암석 사진·실제 재해 증거로 사용하지 않는다.
- 생성 이미지에 버튼·긴 글자·정답 표식을 굽지 않았다. 안전 경로의 통행 영역·장애물은 판정과 정확히 대응하는 코드 도형으로 유지한다.
- 기존 이미지 일부의 제작 조건은 원본 기록이 없어 `assets/CREDITS.md`에 확인 필요로 남겼다.
- 실제 태블릿의 터치 감각·실제 전자칠판·상업 배포 조건 재확인은 이번 PC 브라우저 검사와 구분한다.
