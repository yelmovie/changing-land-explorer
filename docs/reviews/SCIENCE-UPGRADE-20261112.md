## 검토 범위

## 실제 반영한 수정

1. 30개 발견마다 짧은 과학 관찰 포인트를 표시했다. 침식·운반·퇴적, 상류·하류, 모형, 분출물, 표본, 전체 색과 알갱이, 시간 변화, 몸 보호를 해당 활동과 연결했다.
2. 활동 제목·안내·피드백·관찰 수첩·현장 임무에서 핵심 과학 용어를 같은 색과 굵기로 강조했다. 강조 마크를 제거한 본문은 원문과 같아 기존 음성 연결을 유지한다. 저장된 글은 HTML로 실행되지 않도록 이스케이프한다.
3. 활동 마지막 버튼을 ‘개념 정리’, 두 번째 개념 정리의 다음 버튼을 ‘현장 임무로’로 고쳤다. 실제 도구 보상은 현장 임무를 마친 다음 제공한다.
4. 화산 임무를 용암의 뜨거움, 화산재의 작은 고체 알갱이, 붉은 물 모형과 실제 분출물의 차이로 연결했다. 마지막 문제에서 모형과 실제를 혼동하면 다시 비교하도록 안내한다.
5. 일반 선택지는 같은 시각적 강조를 사용하고 단계별 배치를 바꿨다. 관찰 자동재생은 0.5·1·2·3배속을 제공하고, 정답 선택 직전과 수동 개입 시 멈춘다.
6. CSS 물줄기와 마을 상태 상자를 새 강 관찰·화산재 교실 삽화로 대체했다. 화산에는 분출물 그림을, 지진에는 기존 책상과 몸을 보호하는 리버를 합성한 장면을 사용했다. 몸 보호 개념 영상의 사각형 책상도 같은 삽화로 교체하고 손과 책상 다리의 위치를 맞췄다. 현장 임무의 몸 보호 단계는 교실 배경을 쓰고 대피 단계에서 야외로 전환한다. 이동 격자는 길과 충돌을 판단하는 조작판으로 유지했다.
7. ‘직접 분출’을 ‘붉은 물 흐름’으로 바꿨다. 마그마와 용암을 구별하고 기체는 나오는 위치를 표시한 것임을 영상 설명에 명시했다. ‘비옥한 토양’은 ‘식물이 자라기 좋은 흙’으로 풀었다.
8. 강 개념 영상의 일반화에 ‘대체로’를 넣고, 화산 영상의 기체 표지를 발생 위치를 뜻하도록 바꿨다. 용암 표지선이 풀밭을 가리키던 위치도 실제 붉은 용암 흐름으로 옮겼다. 편집 소스와 배포용 영상을 함께 갱신했다.
9. 작은 가로 화면에서 안내와 조작 영역 높이가 달라지면 배치를 다시 계산하게 했다. 667×375의 대피 조작은 3열로 배치해 48px 이상 버튼을 유지한다.

## 오개념 방지 확인

- 마그마는 땅속의 녹은 물질이며, 지표로 나온 것은 용암으로 부른다. 암석은 색 하나나 구멍만으로 일반화하지 않고 두 표본의 색과 알갱이를 비교한다. [NPS 화성암 자료](https://www.nps.gov/subjects/geology/igneous.htm)
- 화산재는 작은 고체 알갱이다. 눈에 보이는 분출 구름을 기체 자체의 모습으로 단정하지 않도록 발생 위치 표지와 설명을 구별했다. [USGS 화산 기체 자료](https://www.usgs.gov/publications/volcanic-gas)
- 화산 물질이 토양으로 변하는 과정에는 오랜 시간이 필요하다. 화산의 이로움은 시간과 안전 조건을 함께 제시한다. [USGS 화산 활동의 이로운 점](https://www.usgs.gov/faqs/what-are-some-benefits-volcanic-eruptions)
- 화산재 때 창문 닫기, 실내 대기, 공식 안내 확인을 연결했다. [국민재난안전포털 화산 행동요령](https://www.safekorea.go.kr/safekorea-kor/em/emergency/emergency_er5.html)
- 지진 때 몸 보호와 흔들림이 멈춘 뒤의 대피를 구별했다. 튼튼한 책상 아래, 머리 보호, 책상 다리 잡기, 선생님 안내, 계단과 넓은 장소를 순서대로 확인했다. [국민재난안전포털 지진 행동요령](https://m.safekorea.go.kr/safekorea-kor/em/emergency/emergency_eq2.html)

## 검증 기록

단위 테스트 170개와 JavaScript 구문 검사, 320개 파일의 최종 빌드를 통과했다. 개념 영상 MP4·WebM 20개 모두 15초·1280×720과 하단 문장 표시를 확인했다. 영상 3편은 최종 인코딩의 13초 화면을 직접 열어 표지 위치·몸 보호 자세·잘림을 확인했다.

- 활동은 9개 크기 270상태에서 667×375의 한 조작 겹침을 발견했다. 수정 뒤 해당 크기 30상태 전체와 완료 상태 120개를 통과했다.
- 현장 임무는 9개 크기 396상태를 통과했다. 마지막 버튼·이미지 조정 뒤 3개 크기 132상태를 다시 통과했다. 공개 화면에서 발견한 교실·야외 배경 전환을 보완한 뒤 같은 132상태를 다시 확인했다.
- 공통 UI·힌트·모달 270상태, 최종 빌드의 개념 화면 120상태와 재생·일시정지·재시작·실패 시 대체 안내를 통과했다.
- 실제 포인터 조작으로 30발견, 10개념, 5현장 임무·보상, 주민 도장, 기록탑 3라운드, 엔딩·인증서·새로고침을 완료했다. 도착 음성 20대화와 음원 27개 디코딩, 관찰 자동재생 9조건도 통과했다.
- HyperFrames의 정지 프레임 재사용 경로에서 하단이 잘리는 문제를 발견했다. 재사용을 끄고 전체 프레임을 출력했으며, 실제 영상의 하단이 비면 배포용 파일 교체를 중단하는 검사를 추가했다.
- 새 삽화 2개를 단계별 자산 목록에 넣어 처음 방문하기 전에도 오프라인에서 사용할 수 있게 했다. 작업 관계 그래프를 4,880노드·8,836관계로 갱신했다.
